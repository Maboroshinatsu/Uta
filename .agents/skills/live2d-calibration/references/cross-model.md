# 跨模型标定

- 批量测试时，按模型记录台上资源、签名、参数范围、发出试验时和采样时的帧号。热切换样本与冷启动样本分开。帧停滞、旧模型仍在台上或换姿态后连续出现上一组读数时，重采该项。
- 能力档案不可用时，仍可从 Cubism Core 读取参数范围，并从模型声明的物理文件找输入和输出。给实验副本记录独立资源哈希，同时标明应用能力档案缺失。重音的两张贴图超过 Uta 的单资源扫描上限，仍能渲染和播放原生动作。
- 先读物理组的输入和输出，再沿上游测试。冰糖的 `ParamBodyAngleX` 是物理输出，`ParamBodyAngleXinput` 能在头部保持中位时驱动身体。这个映射仅用于已核对的冰糖资源；其他模型可能只支持从头部联动身体。
- 把数值到位、局部可见、正式播放、正式停止分别记录。miku 的身体 X/Y 在默认姿态下可写入且未见形变。发丝或服饰基线不稳时，用脸部或躯干局部对照；该区域也漂移时，保留为待复测。
