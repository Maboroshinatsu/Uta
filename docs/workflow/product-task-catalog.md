# 产品化实施任务包与交接模板

日期：2026-10-23。本文是完整任务目录，不是实时派单队列。当前以[CURRENT](CURRENT.md)和各批主控审查为准：Bento语音mock、模型能力纯模块/真实Core读取、设置存储内核/开发profile十二字段接入、Soullink隔离试验均已交付；完整迁移/独立窗口/表现仲裁与持续runner仍未完成。下方批次总图保留最初依赖设计，不代表还应重派已完成部分。下一批建议见[后续任务计划](NEXT-BATCH-PLAN-2026-10-23.md)，尚未armed；研究任务见[研究派单](tasks/product-performance-plan.md)。

## 1. 通用执行合同

每项都继承根 AGENTS、[产品方案](../PRODUCT-PLAN-2026-10-23.md) 和 [持续开发规则](continuous-development-plan.md)。一任务一worktree/profile；未指定模型素材不碰日常模型；不改main/stable，不全局安装；禁止回退日常端点。所有新增路径都是建议布局，先查现有职责，避免同功能多份实现。

冻结基线：实施前由主控填写 main 的完整 SHA 和契约 bundle/hash，不用浮动 `latest`。两任务共享文件必须顺序执行或由单独集成任务修改。允许目录不是授权无限重构；只可修改任务行为所需文件。

默认验收：目标模块有真实行为测试（状态、边界、释放/失败），不写只匹配源码字符串的测试冒充功能。按影响执行 typecheck/build、对应应用/插件测试。仓库 `app/package.json` 和 lockfiles 的变更集中由主控登记；Worker交新增测试路径/依赖请求，不自行并行改脚本。

每项结果写 `docs/workflow/results/<task-slug>.md`；机器运行记录在仓库外。提交前核对 diff 仅本任务，交真实命令/退出码，未运行写未运行，GUI与声音必须单列。功能交付到 submitted，等主控审查。

## 3. 基础任务

### [C01：冻结跨窗口、表现与派单契约]

- owner：Codex；依赖：用户确认实施方向。
- 范围：新增 `docs/contracts/` 类型草案/JSON fixtures/版本约束；专属任务可新增 `app/src/shared/` 契约文件。不改产品行为。
- 必须固定：settings schema/revision、read/patch/subscribe响应、冲突/校验/失败语义；窗口状态与手动最小化意图；PerformanceIntent/Profile/Snapshot；任务状态与结果格式。
- 成果：每个接口至少正常/缺失能力/冲突/取消/旧generation fixture，冻结枚举、单位、默认与上限；实现路径owner表；旧接口映射。
- 验收：能由两个Worker独立据fixture实现；未知字段/旧版本拒绝策略明确；不把所有对象做无限Record逃避契约。
- 停点：需要用户选择的新产品行为在文档列出，不由Worker凭视觉稿决定。

### [C02：旧行为基线与模型验收素材清单]

- owner：Codex；依赖：无，可与契约并行。
- 范围：新增 `docs/validation/` 规范与回放输入fixture；不提交模型资产/私人内容。
- 内容：录制60–90秒统一事件脚本，三类模型参数清单、当前原生资源/设定、fps与机器环境；收集“原生动作+口型+表情+注视”和“换模/中断”对照。
- 验收：每段输入有时间、seed、预期状态、实际旧结果与画面路径；不能把尚未复现的问题列为已确认根因。
- 未具备GUI/模型权限时：先交fixture与待录项，状态为部分完成，不伪造画面。

### [Q01：有限任务队列与租约状态机]

- owner：Qoder；依赖：C01契约冻结。
- 范围：新增 `scripts/dispatch/state.*`、`scripts/dispatch/storage.*`、`scripts/dispatch/tests/`；不调用真实平台、不自动执行代码。
- 行为：任务依赖ready计算、原子租约、事件日志/快照、预算、幂等run、pause/cancel/recover状态。跨owner候选不自动视作集成依赖满足。
- 验收：模拟两个调度器抢同一任务；重复事件、损坏尾日志、原子写中断、租约过期但进程活着、合同哈希改变、批次预算到界限。未知完成状态禁止重投。
- 非目标：UI仪表盘、云队列、真实GUI、Windows服务安装。

### [Q02：Qoder与Antigravity执行器隔离]

- owner：Qoder；依赖：C01，串行核实平台配置。
- 范围：新增 `scripts/dispatch/platforms/` 和相关测试；必要插件隔离修复另列 `plugin/` 指定文件清单，不能泛改所有宿主。
- 行为：argv数组启动官方CLI、工作目录/env白名单、模型策略、init/result解析、指定session续接、有限取消；工具权限与任务类型匹配。
- Antigravity前置：验证独立CLI配置能阻断旧插件，或修SDK v2隔离。无人值守不能依赖未经恢复验证的全局停用。
- 验收：fake CLI事件格式测试 + 每平台真实最小任务，模型请求元数据与实际返回分别记录；禁MCP任务无桌宠动作；取消无遗留所属进程。
- 停点：需要改真实账号/全局插件/认证流程时交主控；不能把旧CLI版本假定为永远支持相同flag。

### [Q03：有限队列运行、恢复与摘要]

- owner：Qoder；依赖：Q01/Q02集成，或明确批准同owner任务栈。
- 范围：`scripts/dispatch/` runner/命令/测试、使用文档；不改AGENTS总规则。
- 行为：validate/arm/run/status/pause/cancel/recover/collect；run不隐式arm；脱敏摘要；退避与attempt预算；进程身份检查；输出失败与退出码分开。
- 验收：调度器故意中断后恢复，确认“已完成但未收集”只collect；两平台各一项真实续接；主控停止后另一个ready任务继续；main与stable不变。6小时演练作为阶段门槛，不由短探针替代。
- 非目标：自动购买额度、自动发消息、自动main合并、无限重试。

### [A01：Bento组件规范与语音代表页（原蓝色代表页任务）]

- owner：Antigravity；视觉以用户已确认的[bento-design-decision](../design/bento-design-decision.md)为准，覆盖旧大蓝色块要求；依赖C01字段fixture。
- 范围：`docs/design/` 的本任务稿件；实施时限定新增 `app/src/renderer/components/settings-v2/` 的tokens/基础组件/语音代表页，不接真实存储/设备。
- 行为：浅灰白Bento表面、品牌蓝强调、六域导航、基础设置行/段落、草稿表单、校验/保存/失败/重试、键盘与中文输入法状态；深浅色/窄窗。已有mock交付，后续真实接线需新任务单，不重派视觉重做。
- 验收：1280×720和1024×640、系统125/150%缩放、长名称/密钥提示/错误行，标签不断裂、主要操作可见；对比度检查；busy不误触；reduced motion。
- 非目标：装新UI库/重建全站、用多层卡片代替结构、实现未存在的设备/服务API。

### [A02：统一持久设置与来源迁移]

- owner：Antigravity（按批次负责数据底座；此前Qoder设计作为输入）；依赖：C01与既有 `results/settings-migration-design-review.md`。
- 范围：主控明确列出的 main settings服务、新IPC handler、preload和shared契约、renderer settings client/store；该时段此范围独占，其他UI只用fixture。
- 行为：每profile唯一主进程写入权威；schema/revision；原子写、备份、乐观冲突检测；启动gating；开发origin/打包origin旧来源一次性导入，不镜像写旁车。
- 验收：同profile两窗口更新/冲突、不同profile不串写、迁移冲突保留来源、损坏JSON恢复、旧版本备份、保存失败不显示成功、订阅清理、密钥脱敏。
- 停点：旧来源无法无歧义判断时交用户选择；不得靠mtime猜出用户最想保留的设置后直接覆盖。

## 4. 表现系统任务

### [Q04：模型能力Profile与校准覆盖]

- owner：Qoder；依赖：C01、C02。
- 范围：新增纯模块 `app/src/renderer/services/performance/profile/`；静态资源读取走现有安全入口，需新主进程能力则单列接口变更；不直接改renderer loader大段。
- 行为：融合真实Core参数范围/默认、model3/CDI、原生motion/exp3目录；区分事实/推断/用户覆盖；签名和覆盖版本；未知/低置信度不激活。
- 验收：参数不存在、反向/非对称范围、离散特效、Add/Multiply/Overwrite、缺CDI、模型更新签名、损坏动作、路径越界/符号链接边界；只读模型目录。
- 成果：capability summary、coverage理由、fixture、从旧emotion-adapter到新profile的兼容策略。

### [Q05：Soullink纯引擎适配选型试验]

- owner：Qoder；依赖：C01/C02、参考研究；单独实验分支。
- 范围：隔离benchmark/adapter原型与ADR；依赖变化先交主控批准，不进入产品默认路径。
- 比较：Soullink受支持public API可用范围、internal API风险、包体/分配/耗时、口型全时归零策略、情绪持续时间、私有参数校验；对照Uta自有纯模块方案。
- 验收：相同fixture/seed产生合法输出；第三方默认不能替用户设置/旁车；记录beta精确版本或源码SHA与许可证/NOTICE；给出采用/裁剪/参考自研的理由。
- 停点：不把PIXI7 renderer引入Uta，不在两个runtime同时写Core；选型未裁决不推进依赖第三方特有类型的产品API。

### [Q06：按通道仲裁、平滑与生命周期]

- owner：Qoder；依赖：Q04、选型ADR裁决；C01通道表。
- 范围：新增 `services/performance/mixer/`、时钟/owner模块与测试；不改loader接线。
- 行为：replace/add/multiply、有界强度、per-channel mask、渐入/渐出、owner generation、过期/取消、换模清理；物理前/后贡献分离；单调时钟/dt保护。
- 验收：并发层不越界、旧release不能解新owner、嘴形与开合分离、闭眼与眨眼组合、物理输出不反馈；固定dt序列可复现；休眠恢复稳定。
- 成果：诊断快照、控制权测试表；保留当前预设的转换fixture。

### [C03：表现适配器接线与旧路径迁移]

- owner：Codex，主控不在线时等待；依赖：Q04/Q06集成；单独占用loader、Stage渲染循环、预设/表情入口。
- 行为：先只计算不写，后逐通道迁移；现有motion/expression走适配命令；口型、呼吸、注视保留各自阶段。每迁一类列明停用旧路径。
- 验收：旧预设、原生动作/物理、编辑锁、换模、断线、关闭均回归；模型上可切回旧路径且没有双写；至少一段真实GUI对照。
- 理由：这是高冲突公共接线，不应让两个Worker各自改一半，主控失联时停在可审查纯模块是明确设计。

### [Q07：情绪状态、自然待机与表现导演]

- owner：Qoder；依赖：Q06接口；真实接线等C03。
- 范围：新增 `services/performance/director/`、情绪/idle纯模块，fixture/test。对外只有语义意图，不直接Core写。
- 行为：可信任务状态编排；连续情绪平滑/衰减；种子化低幅变化、冷却/去重/动作预算、安静模式；缺能力降级；不让随机微动永久占用高帧。
- 验收：固定60–90秒脚本、事件重复/乱序/取消、断会话、任务失败、待审批、缺native motion；不把thinking推断为错误，不把进度当成功。
- 非目标：文本情感模型/LLM逐帧控制、MAGIC训练。

### [Q08：真实语音边界与句级表现]

- owner：Qoder；依赖：C03、Q07，语音接口已冻结。
- 范围：`services/performance/speech/` 与现有mouth-motion的明确增量；Stage公共接线由主控独占提交。
- 行为：沿用真实幅度口型，统一播放时钟/停顿/结束/取消；可选句级头身眉眼重音；口型释放尾/闭合保护可调且A/B，避免两次平滑叠加。
- 验收：TTS请求成功但播放失败、缓冲、静音段、倍速/取消/切源/切会话；结束嘴闭合；无独立元音rig时不显示多元音已支持。实际听音与画面偏移单列。
- 后续实验：音素/元音与MAGIC另建任务，不能为了“全面”塞入本项。

### [A03：回放面板与表现校准UI]

- owner：Antigravity；依赖：A01/Q04/Snapshot契约；真实接线等C03。
- 范围：新增 `components/settings-v2/performance/` 或工坊高级校准子页、回放工具UI；不拥有映射/渲染内核。
- 行为：能力摘要、低置信度建议、可控单参数预览/范围/反向、保存覆盖与恢复；预览有owner且可取消。开发诊断显示当前控制来源、降级与clamp，默认不暴露全部技术值。
- 验收：快速切模型旧结果隔离；关闭窗口释放；保存失败保留草稿；缺参数状态；低频快照不卡；不启动第二个Live2D，模型画面仍由桌宠舞台渲染。

## 5. 设置、创作与交付任务

### [A04：独立设置窗口与状态接线]

- owner：Antigravity；依赖：A02与C01窗口契约。
- 范围：主控指定main窗口模块、preload路由、settings entry；当其他任务改IPC时串行。
- 行为：默认两个窗口、同应用单实例；设置正常resize/最小化/关闭，不连带桌宠；桌宠手动最小化意图保留；审批排队/提醒，不自动批准或普通事件抢焦点。
- 验收：任务栏恢复、托盘恢复、设置关闭/重开、桌宠最小化时外部事件、待审批、穿透、置顶、退出清理。Windows可能分组图标，不承诺固定独立图标。
- 非目标：第三个工坊窗口、多份Pinia镜像写盘、settings页面启动新宿主adapter/音频执行器。

### [A05：六领域设置迁移与能力可见性]

- owner：Antigravity；依赖：A01/A02/A04集成。
- 范围：settings-v2六领域页面及字段schema/search；逐页迁移，主控指定旧组件删除范围。
- 行为：按旧方案迁移清单逐项登记旧字段→新归属→读写来源→默认→迁移→验证。连接表单显式保存、试听不保存；show能力事实而非仅桥accepted。
- 验收：每页正常/加载/空/错误/缺能力；跨窗同步、脏草稿提示、搜索/键盘/IME/缩放；隐藏旧入口前确认功能覆盖。不能只留漂亮空壳。

### [A06：工坊草稿、撤销与动作预览闭环]

- owner：Antigravity；依赖：A03/A05、C03表现锁接口。
- 范围：settings内工坊专用布局与编辑状态；业务保存/预设协议沿既有语义；公共preset控制入口独占整合。
- 行为：动作库/步骤/属性三栏，选中范围、过渡/停留/循环/恢复语义；拖动一次形成一组撤销；预览与保存分开；关闭脏稿提示；保存到用户profile覆盖。
- 验收：旧序列/日常状态兼容；同名另存/覆盖；undo/redo；外部事件不改草稿；关闭/崩溃锁释放；设置窗口销毁后舞台恢复最新状态。

### [Q09：模型与会话生命周期稳健性回归]

- owner：Qoder；依赖：C03/Q08/A04集成。
- 范围：生命周期/状态边界的指定模块与行为测试；不得借回归全重写Stage。
- 行为：换模/重连/窗口关开/音频取消/APP退出清理统一generation；不读取日常数据。
- 验收：快速重复操作100次的受控测试、在途异步返回、订阅/定时器/音频节点释放、失败不回退旧实例；真实GUI长待机与内存趋势另列。

### [D01：DSH宿主兼容性验收]

- owner：DSH（仅测试）；依赖：合并候选与隔离插件产物。
- 范围：测试说明/结果/复现；不改通用开发或其他平台代码。
- 验收：工具发现、v2握手、指定会话绑定、accepted/started与画面证据、取消/结束/最小化。失败交Codex定位，DSH不承担修复外包。

### [C04：集成、ZIP候选与日常提升]

- owner：Codex；依赖：本候选纳入的所有任务通过审查。

## 6. 首个有限队列建议

用户确认→C01/C02完成后，建议先只arm四项：Q01有限队列状态机、A01蓝色组件代表页、Q04模型Profile、Q05纯引擎试验。它们互不修改loader/主进程公共接线。Q01产物尚未验收时，仍通过既有人工CLI派单；不能让未验收runner自动执行自己。
