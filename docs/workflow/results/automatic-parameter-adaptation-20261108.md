# 自动参数适配与统一混合规则

基线：`main@82ce430`。只修改 Live2D 自动映射、参数层及相关调用与测试；保留既有 README 改动，不修改用户模型、预设或发行包。

## 行为

- 模型加载时由实际参数、VTS 绑定及物理关系形成通道映射。明确的自定义头部和眼球绑定也能识别；多个头部/身体候选使用物理关系区分，单一头部输入带动身体时不重复写身体。
- 新增每模型参数混合表，供姿态过渡、实时叠加、物理前输入、物理后保护、SDK 保存基线及释放共用。自定义身体输入不再因为名称不匹配而被当作普通持久值覆盖。
- 预设的眼神锁定与眼球坐标切换使用同一通道分类；VTS 明确绑定的自定义眼睑沿用眨眼缩放规则。普通服装、道具等参数保留原有持久行为。
- 沿用显式适配优先、显式 null 禁用、物理输出不充当自动跟随输入等约束。映射不明确时保留原生联动；没有新增作者/模型名称特判或用户数据迁移。

## 验证

- 新增陌生命名的模拟 rig：包含独立头部、编号身体输入、自定义眼球和眼睑，以及歧义绑定、单一头身联动和切模后通道隔离。
- 参数层回归先在旧版复现覆盖问题；修复后验证 `ParamBodyAngleXinput`、`Param13`、陌生身体名称的叠加、过渡、释放、保存基线、多帧无漂移、物理前输入与物理后保护，另验证自定义眼球/眼睑及原有标准通道。
- 完整应用测试 1421 通过、6 跳过，Node/Web 类型检查和隔离构建通过。全量回归曾发现仅身体绑定的 PositionY/Z 被误当头部，已修正且保留原断言。
- 大肥鱼、冰糖、艾莲资源副本移除 Uta 适配器与预设侧车，并改为匿名模型文件名、同步同名 VTS 文件。三个副本的运行时均报告 `adapterSource: none`、无显式 focus，自动识别身体输入及眼球方向。纯参数待机连续循环时身体保持跟随，左右、关闭/开启、表演打断后恢复通过；已查看实际渲染截图。Hiyori 标准模型同路径通过。
- 三个模型原有真实待机预设另以副本验证：大肥鱼原生循环保留身体跟随，冰糖/艾莲静态待机结束后释放原生动作所有权。纯静态待机不要求存在参数时间线运动。
- 用户已授权重载当前开发版；本轮验证后执行完整 renderer 重载，并通过明确指定的开发端点确认模型 revision 更新。未将该检查当作用户真实鼠标和主观观感验收。
- 本机受控证据位于忽略目录 `app/node_modules/.cache/automatic-adaptation-evidence/`；读数含模型资源签名、自动映射和实际渲染值。探针为同级 `automatic-adaptation-probe.cjs`。输入端固定鼠标目标，正常播放器、参数层与物理均保留；它不代替真实鼠标输入链路及所有模型的观感验收。

## 边界

- 这是依据已知结构的自动适配，不是自动理解任意编号参数或自动视觉标定。缺失/歧义元数据、特殊非线性耦合及幅度观感仍可能需要显式配置。
- 自动映射不代表复制大肥鱼专属原生动作，也不强制其他模型采用它的身体比例或轴禁用设置。原有显式配置仍优先。
- 未打包、未更新全局插件；测试 profile 与模型均为副本，测试进程退出后由探针清理自身临时根目录。
