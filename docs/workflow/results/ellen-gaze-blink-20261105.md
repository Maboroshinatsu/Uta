# 艾莲身体跟随与自动眨眼

- 测试模型为免费模型艾莲。隔离实验资源签名为 `lab-sha256:a4496b307bbeec92781ba2098fb0e0078d67e5da517bdf6f4470f4d36b3c16ca`。常规播放器与标定工具均使用模型副本。
- 导入生成的适配器只声明头眼。旧运行时将缺省身体 X 指向物理输出，实际身体输入始终为零。现在按轴补齐省略的身体映射。对于带辅助输入的同轴物理组，只在同名 VTS 配置确认唯一输入时驱动该参数。适配器明确设定的参数或 `null` 仍优先。
- 艾莲把 `Param13`、`Param14` 同时列为 `EyeBlink` 和身体物理输入。基线关闭跟随时，自动眨眼仍让它们在 0 与 1 之间变化，身体 X 输出在约 −2.77 与 2.13 间振荡。修复在自动眨眼的眼睛通道中排除该类身体输入，保留明确的眼睛绑定与原生动作通道。
- 修复后艾莲左右、上下输出约 ±10，斜向有倾斜，关闭跟随后三轴回到零。超过五秒的固定目标和关闭跟随采样中，眼睛继续眨动，`Param13/14` 不随之变化。单独播放原生 `idle2` 时，这两个通道仍按模型动作曲线运动。
- 冰糖保留身体输入映射，RetrynowMiku 保留头带身体联动，大肥鱼保留专用身体映射和反向眼球。Node 与 Web 类型检查、隔离构建通过，应用测试 1354 通过、6 跳过。
