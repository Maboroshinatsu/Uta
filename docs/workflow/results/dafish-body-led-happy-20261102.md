# 用户否定V3后的身体主导开心修正

用户反馈V3动作幅度几乎不可察觉、极慢、头以外的身体像没动。这一反馈取代此前“参数有效/录屏已查”的交付判断；V3不是已通过观感验收的版本。

## 修改

基线`main@770ad33`。`12ebb75`修复视线关闭时把全身画布中心当作跟随目标的问题：脸部原点不在画布中心，错误会把AngleY和PositionY拉到-30。新的resetLive2DModelFocus直接使跟踪偏移归零；回归通过真实渲染循环验证。

`413966e`新增V4「开心·身体主导样板」，ID `dafish_body_led_happy_v4`，6.4秒，保留所有旧样板。主要身体X/Z峰值由V3的1.8/1.3增到12/16；Y峰6.5、LeanInput峰5.5。手势抬起约.74秒、放下1秒，取代原2.1/3.7秒。头部仅小幅配合，并提供头部输入全零的诊断变体。复用的是我们自己的独立脸部轨道，没有读取自带动作曲线。

另将新预设第一空生命周期步骤改为200ms过渡+1400ms保持，总时长仍1600ms。步骤用于交接视线和显示阶段，不再把整段1600ms都用于退出视线跟随。
