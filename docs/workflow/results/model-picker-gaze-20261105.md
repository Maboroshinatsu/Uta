# 模型切换同步、列表折叠与视线跟随

- 主进程收到桌宠的模型上下文后，只在模型路径、就绪状态或桌宠文档变化时通知设置窗口。设置窗口通过现有命令读取带代际标记的快照，更新当前模型和控件。静态立绘模式会清除 Live2D 能力与滑块。
- 在隔离实窗禁用模型路径写入，从快捷设置将冰糖换成 RetrynowMiku。基线的大设置仍显示冰糖。修复后大设置更新标题和列表的“当前使用”，探测到桌宠提交后约 83 毫秒完成显示同步。
- 更换模型列表从自身高度过渡到零，减少动态效果模式下立即收起。实窗采样中，基线长列表一开始突跳 369 CSS 像素，两种长度收尾均再跳 44 像素。修复后的短、长列表约 240 毫秒收起，起始和收尾位移至多 1 像素。
- 自动视线映射以 Core 参数和模型物理定义为依据。身体物理只沿单一同轴角度输入驱动，使用物理反向标记调整方向。无法确定输入时保留可用的头眼控制，明确的适配器 `focus` 映射优先。
- 冰糖的左右、上下身体输出由基线的 0 变为约 ±10，斜向有倾斜，关闭跟随后三个身体轴回到 0。实窗截图可见躯干转动。RetrynowMiku 的身体仍由模型原有的头部物理驱动。miku 的水平身体参数仍随视线更新。大肥鱼继续使用 `PositionX/Y`、`AngleX/Y/Z` 与专用眼球方向，关闭跟随后回正。
