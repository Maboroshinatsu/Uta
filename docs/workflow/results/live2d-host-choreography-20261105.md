# Live2D 校准和宿主动作编排

## 实现

- 开发校准 skill 验证目标模型在台、试验帧推进、局部基线、滑块连续换向、循环释放和打断。实验工具对缺少正式能力档案的副本记录 `lab-sha256:` 指纹。
- 工坊单步预览以同一过渡释放旧情绪层和应用新姿态，避免旧姿态污染 Cubism 保存的参数。关闭工坊预览时清除所持滑块与部件，停止底层预览动作。
- 参考鲸语先编排时间线、再做本地校验和回执的方式。宿主 LLM 从当前模型获取输入参数，把并行变化写成共享时钟上的轨道。Uta 校验范围、时间、通道所有权及模型版本，编译为现有预设工坊的关键帧并播放一次。
- `deskpet_motion` 支持 `capabilities`、`validate`、`play`、`status`、`stop`。动作回执按所有者隔离。编排期间，自动工作状态保留界面更新并让出动作控制。预览锁定或旧模型版本会明确拒绝播放。
- Codex 和 Claude Code 随包提供技能文件。共享 MCP 暴露工具和 `uta_live2d_motion` 提示。DeepSeek Harness 在原生 Uta 技能中登记动作入口。OpenCode 安装时随事件插件部署 MCP，启动时沿用已有同名服务或挂载随包服务。

## 验证

- miku 和重音分别跑了基线、正向、反向、回归四组实窗标定。每组都观察到新帧。重音的正式能力档案缺失时，实验指纹仍可生成并完成参数验证。
- miku 工坊键盘往返复测到达 `-30`、`+30`、`-30`、`+30`，Cubism 保存的基值保持 0。六个兼容性样本释放原生循环后，队列均结束，等过下一轮也未重启。
- 隔离 Uta 与打包 MCP 实测「侧目、微笑、回正」双轨。头部保持 `-14` 时嘴形到 `0.65`，宿主完成事件期间继续播放。完成、停止并回到基线、工坊锁、跨宿主和跨会话隔离、切换 RetrynowMiku 后拒绝旧计划均通过。
- Codex、Claude Code、Qoder、ZCode、Antigravity 和 OpenCode 的随包 MCP 均能列出动作工具和提示。OpenCode 1.14.31 实际隔离服务器报告 MCP 已连接。DeepSeek Harness 原生技能注册与工具调用由插件测试覆盖。
- Node 和 Web 类型检查、隔离 Electron 构建、插件构建通过。应用测试 1349 通过、6 跳过。插件测试 133 通过。

正式播放器完成回执记录时间线执行结果。动作的画面表现通过实窗检查，随包工具发现和受控回环验证分别记录。日常发行包与各宿主账号中的自然语言调用未验收。
