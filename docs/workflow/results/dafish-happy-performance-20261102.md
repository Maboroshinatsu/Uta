## 这一版的逻辑变化

不再用若干整身姿态覆盖值承担这段动作。新模块 `app/src/renderer/services/live2d/dafish-happy-performance.ts` 把独立轨道编排为运行时 motion3，再复用现有 Cubism 播放、淡入淡出与物理更新。

1. **身体**：读取本模型「脱捕」的 AngleX/Y/Z、PositionX/Y/Z 连续曲线，保持通道之间原有的相位关系，放缓至 18.6 秒、幅度约为原曲线的 78%。不是移动整张角色画布。
2. **手臂与道具**：第 1.4 秒开始使用本模型「狗尾巴草打开」的原生曲线起手；持拿阶段手腕、小臂、大臂各有轻微运动；第 14.1 秒开始按原生关闭曲线收手，随后接回循环起点。
3. **面部与视线**：分时安排微笑、两次较明显的笑意、眨眼、短暂爱心眼、少量脸红和视线变化；不复制「脱捕」中的圈圈眼、加载、呆滞等内容。
4. **所有权**：这段动作运行时，其自带轨道可以接管底层默认值，避免手臂/道具被原 adapter 的默认参数压回去。明确的用户控件、情绪和说话口型仍走原有优先规则。待机微表现与随机空闲动作在样板期间让路。
5. **收尾**：循环接缝对齐，停止或换动作后立即释放本实例的轨道所有权。切回日常待机后实际画面未残留狗尾草。

真实模型最终生成 27 条可用参数轨道。只使用模型实际存在、且不是物理输出的参数；缺少必要原生资源时不注册，也不在可选预设里暴露这个样板。轨道编译只在模型加载时执行，播放期间由原有播放器逐帧求值。

## 代码接线

- `dafish-happy-performance.ts`：原生 Cubism 曲线解码、非均匀时间贝塞尔求值、表演编译、实例内动作缓存与所有权。
- `useStageModelLifecycle.ts`：仅大肥鱼适配识别成功且编译成功后注册生成动作和能力信息。
- `natural-presets.ts` / `deskpet.ts`：提供独立样板条目；对已有模型桶只追加这个条目一次，不替换原开心预设；删除后不在每次加载时重加。没有升级全局预设版本或迁移所有状态。
- `loader.ts` / `usePresetController.ts`：处理默认参数、视线与生成轨道之间的接管关系。
- `useCompanionDirector.ts`：背景随机待机不打断正在播放的样板；其他动作接管后恢复原逻辑。

四个空参数分镜仅维持现有控制器的视线与生命周期计时；真正的身体、手势、表情运动全部在连续曲线上，不是这四个分镜之间的静态插值。原生动作只在开始时触发一次，不在每个分镜重新起播。
