# 原生动作和临时部件编排

- 共享 `deskpet_motion` 能力返回原生动作的组名、索引、时长与已知写入范围，以及可用的部件控件和档位。技能先选择匹配的模型资源，再用参数轨道补充细节。模型切换后重新取能力和版本。
- 版本 1 时间线支持一个原生动作及多个部件状态变化。状态变化从 `atMs` 开始生效，空数组释放该段的临时部件。Uta 使用预设播放器校验和回收控件。原生动作与同一通道的控件或滑块发生冲突时拒绝编排。
- 原生动作可导出为一次性预设草稿，保留准确的组名和索引。无名称的动作组用原文件名作为能力标签，引用仍保留空组名。单次动作要求已知时长并受 12 秒时间线上限约束。
- 共用 skill 要求以实际模型输入和资源编排主动作、头身错峰、表情及收尾，避免默认值轨道占用无关通道、长时间闭眼过渡和手臂绘图切换冒充连续抬手。时间线的所有关键帧合并为共享节奏点并逐段缓动；skill 明示密集插帧的顿挫风险，独立连续曲线仍未实现。
- skill 区分一次性 `play` 预览与导入后的 hold/loop 验收，要求先预览代表动作再扩展整套；工具没有画面读取能力时明确由用户观察，不把 completed 当作自然度证明。
- 本轮插件 134 项测试通过，生成的 5 份 skill 与共享源文本相同，技能格式校验通过。Antigravity 工作区副本只更新 `SKILL.md` 和 `runtime/deskpet-mcp.mjs`，其 manifest、hooks 与 MCP 配置保持原样，旧文件备份在插件发现目录之外。实际部署文件的新 MCP 进程完成 initialize、tools/list、prompts/get，动作工具说明和提示词均与源文本相同；宿主现有进程仍需刷新 MCP 并重开会话。
- 隔离 Electron 通过 Antigravity 路由的共享 MCP 实测大肥鱼「竖手指打开」和「黑框眼镜」组合。记录到原生动作启动与眼镜参数写入，完成及中途停止后眼镜均释放。艾莲无名称组的第 2 条 `idle2` 实际启动并完成。两种动作都生成了含原生引用的预设草稿。
