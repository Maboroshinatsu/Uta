## 大模型 ZIP 反馈后的源码修复（尚未打包）

- 反馈为 ZIP 导入提示文件包过大。受控复现单文件 64 MiB 上限，以及 ZIP 对不导入的 PSD 计入资源预算；同一小模型附带 65 MiB PSD，文件夹导入成功，ZIP 失败。
- 单文件资源上限为 256 MiB，导入资源合计与 ZIP 文件上限分别为 2 GiB。跳过的文件保留路径、重复名称、符号链接及条目数量检查，不解压、不占资源字节预算。有效资源仍按流核对实际解压字节数。
- 新增 6 项回归，包含实际 65 MiB 资源的文件夹及压缩 ZIP 导入；其余巨大容量边界通过声明或文件元数据模拟，未把模拟边界测试称为真实大模型渲染验收。
- 应用 1405 通过、6 跳过，Node/Web 类型检查通过。未取得反馈者的实际模型包；显卡能否加载该模型尚未验证。
