# 自动跟随与艾莲水印

- 自动映射用同名 VTS 配置确认可写的头眼参数、眼球方向和身体各轴幅度。物理中存在额外身体输入时，优先使用由 VTS 明确绑定且能唯一确定的同轴角度输入。已由头部物理驱动的身体保持原有联动。显式适配优先。
- 在隔离副本停用大肥鱼的专用跟随映射，验证 `PositionX/Y/Z`、反向眼球与回正。冰糖与艾莲走各自的独立身体输入，RetrynowMiku 的身体由头部物理带动。保留大肥鱼内置适配的身体 Z 禁用设置。
- 通用隐藏策略补充识别明确命名的水印网格。艾莲资源签名 `uta-live2d-assets-v1:a4496b307bbeec92781ba2098fb0e0078d67e5da517bdf6f4470f4d36b3c16ca` 的下方字样同时出现在 `ArtMesh183` 与 `ArtMesh255`。实测隐藏整个 `ArtMesh183` 会损坏脸部。应用仅在该签名过滤已经校对的文字纹理区域，保留脸部三角形，并隐藏纯文字的重复网格。模型文件保持原样。
- 新导入时，VTS 生成的绑定保存在 `generatedFocus`，用户显式提供的 `focus` 仍优先。资产签名精确匹配大肥鱼且无显式 `focus` 时，使用内置配置。空白配置实窗从无 Uta 适配器的资源导入后，眼球 X 反向、身体 X/Y 跟随，斜向时 `PositionZ` 保持为零。
