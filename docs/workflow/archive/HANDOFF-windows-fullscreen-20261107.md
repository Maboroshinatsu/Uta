# Uta 交接现场

更新于 2026-11-07。上一轮见 [AstrBot 适配归档](archive/HANDOFF-astrbot-parity-20261107.md)。

## 1. 仓库与版本

- Uta 分支 `main`，基线 `f60dee2`，开工时工作区干净。用 `git status --short --branch` 和 `git log -4 --oneline` 核对。
- Windows 独立探针检查前台窗口与桌宠是否在同一显示器，依据客户区覆盖和窗口样式识别全屏。Electron 从最大化进入全屏后可保留最大化标志，应结合标题栏样式判定。桌宠恢复使用 `showInactive`。

## 2. 运行现场

- 用 `Get-CimInstance Win32_Process` 核对开发实例。实窗验证用独立 Electron 测试窗口和系统 Win32 API。

## 3. 验证状态

- 隔离 Windows 实窗覆盖普通最大化、原生全屏、无边框全屏、退出恢复和焦点。应用测试复跑 1381 通过、6 跳过，类型检查和隔离构建通过。

## 4. 已知未修问题

- 本机部分旧 Codex 聊天的名称只在 SQLite 状态库。Uta 不从 SQLite 补拉缺失的标题。Qoder 等未提供实际标题的连接器仍可能显示未获取标题。
- Codex 连接器共用客户端的逐次 `env` 会覆盖握手默认的 `UTA_HOST`。仅发布宿主共享端点时，握手可达，工作和完成事件可能找不到桌宠。
- Uta 气泡缺少附件发送入口。两类伴侣的部件控制、状态重置、单轮语气、跨设备连接及旧版数据导入仍待实施。截图和摄像头不在当前批次。

## 6. 下一步建议

- 实机复验覆盖独占全屏游戏与多显示器。宿主固定与自动选择策略待确认。

## 7. 未核实项

- 未在实际游戏中验证独占全屏，也未进行多显示器和发行包验收。
