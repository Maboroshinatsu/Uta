## 4. 已知未修问题

- Live2D 参数动作仍按共享节奏点分段过渡；缺失/歧义元数据、特殊非线性联动及其他第三方模型观感没有完整覆盖。循环首尾姿态不同仍会直接跳变，播放器不修改动作本身。
- 长原生动作的临时 MCP 编排仍受 12 秒限制；模型动作库与预设可保留长片段。目录兜底扫描深度有限，深层资源应在清单声明。
- Live2D 发布条件及素材权属仍待对外发布前确认，见 [候选包准备记录](results/open-source-release-preparation-20261107.md)。
