更新于 2026-11-07。上一轮见 [MaiBot 媒体归档](archive/HANDOFF-maibot-media-20261107.md)。

## 1. 仓库与版本

- 分支 `main`，本轮基线 `ecfd4c8`，开工时工作区干净。用 `git status --short --branch` 和 `git log -4 --oneline` 核对。
- MaiBot 适配器 0.4.0 提供能力查询、情绪、预设、动作和表情包工具。SDK 将自定义元数据放在嵌套字段中，适配器把平台和私聊限制放到 Host 注册表读取的位置。执行端再次核对会话来源。

## 2. 运行现场

- 用 `Get-CimInstance Win32_Process` 核对开发实例，用 `Get-NetTCPConnection -LocalPort 8524 -State Listen` 核对 MaiBot 监听。验证使用隔离端口和模拟消息网关。现有开发实例及日常配置未操作。

## 3. 验证状态

- MaiBot 注册表实测在 Uta 私聊中列出 5 个工具，在 Uta 群聊和 QQ 私聊中均隐藏。隔离回环测试覆盖模型能力刷新、宿主绑定、角色指令与表情包投递。适配器 22 项测试通过，应用测试 1377 通过、6 跳过，Node 与 Web 类型检查及隔离构建通过。

## 4. 已知未修问题

- 本机部分旧 Codex 聊天的名称只在 SQLite 状态库。Uta 不从 SQLite 补拉缺失的标题。Qoder 等未提供实际标题的连接器仍可能显示未获取标题。
- Codex 连接器共用客户端的逐次 `env` 会覆盖握手默认的 `UTA_HOST`。仅发布宿主共享端点时，握手可达，工作和完成事件可能找不到桌宠。
- Uta 气泡缺少附件发送入口。MaiBot 的部件控制、状态重置、单轮语气、跨设备连接及旧版数据导入仍待实施。截图和摄像头不在当前批次。

## 6. 下一步建议

- 实机复验时同步更新 Uta 和 MaiBot 插件。宿主固定与自动选择策略待确认。
