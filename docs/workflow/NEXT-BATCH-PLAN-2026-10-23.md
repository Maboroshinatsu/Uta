# 第三批之后：剩余额度与下一阶段任务计划

日期：2026-10-23。用户报告本次5小时额度剩余16%，要求规划后续任务。本文是待确认的实施提案，**不等于派单或armed批次**。产品源码参考基线 `116ee68a57b010ce1e6344dab6b9c477ecb8c488`；正式派单时主控须在前置验证/修正完成后重新登记确切base、契约hash和独立profile。

## 1. 当前事实与优先级

- 应用521项测试、类型检查、构建通过；设置IPC链路的Electron传输和DOM采用替身，真实Electron验证仍缺。
- 十二个公开字段已在开发profile使用单一主进程存储；stable仍legacy。真正的设置窗口、显式旧来源迁移、完整语音配置接入都未交付。
- Soullink纯引擎试验已完成，尚未进入产品默认路径。无语音时mouthOpen归零、逐通道owner/取消与原生动作生命周期，是直接采用前必须解决的问题。
- CLI可以执行指定任务；持久调度/恢复未实现。Antigravity上一轮只获文件编辑能力，命令执行被拒绝，由Codex承担测试与提交；旧插件仍有隔离问题。
- 视觉沿用已确认的蓝色强调Bento；已有语音代表页是mock，不能因为存储接入完成就直接宣称它能调用真实TTS。

本轮将主控额度优先用于前置真实运行验证、接口冻结和可执行任务包，保留一部分用于交付审查。额度百分比不能精确换算为可完成的任务量；不按16%承诺固定工时或全部验收完毕。

## 2. 建议的实施顺序

1. **Codex：设置接入真实Electron补验与下一批契约冻结**。先消除底座的不确定性，再允许窗口开发依赖它。
2. **Qoder：Live2D逐通道仲裁与生命周期纯内核**。解决表现力的结构基础；只计算与回放，不写真实Core。
3. **Antigravity：开发profile独立设置窗口与公开偏好最小闭环**。沿用Bento，做可使用的有限范围，保留现有其他功能入口。
4. **Codex：分别审查与集成**。两路可在合同冻结后并行，不能互相使用未审候选作依赖。
5. 下一轮才进入DS模型上的影子运行、逐通道真实接线，以及六领域逐页迁移；有声TTS/正式数据迁移/ZIP日常提升各有独立验收。

推荐技术方向：**Uta拥有控制权仲裁、取消和生命周期；Soullink保留为可选语义输出源**。先建立引擎无关的内核，后续是否接其public engine由实测决定。保留现有PIXI/Cubism，避免本次同时承担渲染器升级、SDK移植和表现重写。

## 3. Codex先做：真实运行与契约

输入为当前已验收源码、第三批审查和DS受控快照。实现与验证在独立开发profile中进行，不打开正式数据目录。

真实运行补验至少包含：

- 使用实际Electron main/preload/renderer加载设置客户端，确认当前严格主框架/页面校验在真实进程中成立。
- 两个受控测试客户端读取同一开发profile，保存与广播一致；过期版本拒绝，不自动覆盖；关闭重开仍可读取已提交值。
- 开发悬停淡化不被旧窗口状态覆盖；正常退出等待已接受写入完成。
- 检查原正式设置与stable登记不变；stable零新设置store I/O用隔离fixture验证，不能为测试启动正式profile。

若发现问题，先修复/提交并更新派单base。无法执行的GUI项明确列为未验，不把既有521单测当替代。

冻结两份增量契约：

- **表现仲裁契约**：复用`first-wave-contracts.ts`中的SemanticChannel、ModelCapabilityProfile、PerformanceIntent和PerformanceSnapshot；另行固定贡献结构、数值域/单位/默认锚点、仲裁组合、阶段、时钟、owner/generation、取消释放和诊断。不给第三方特有类型绑定产品接口。
- **窗口契约**：桌宠/设置窗口身份与单实例、每窗口允许的准确页面地址、IPC登记、手动最小化意图、关闭与退出、草稿/冲突/重试。明确设置窗口不加载桌宠App、模型、宿主连接或音频执行器。

给每个任务登记独立分支/worktree/profile、可写清单、只读输入及hash、可执行验收命令、结果路径和停止条件。此时才由用户确认批次并armed；本文不预填假的契约hash或冒充任务目录已存在。

## 4. Qoder：Live2D逐通道仲裁与生命周期纯内核

模型仍固定DeepSeek-Flash，显式请求max思考和1,000,000上下文，实际有效上限不做保证。禁止自行换模型或再派子Agent。

建议允许范围：新增`app/src/renderer/services/performance/mixer/`、本任务测试与交付文档。Profile及现有冻结类型只读；若需要新增shared类型由主控先提交。不得修改loader、Stage、PIXI依赖、产品设置与正式模型。

三个可审查阶段属于同一个有界任务：

1. **通道控制权**：按明确通道进行replace/add/multiply、mask和优先级组合；保留native输入基底；不把一个全局优先级数字应用于所有部位。
2. **生命周期与过渡**：owner/generation、模型epoch和会话边界；渐入/渐出、单调时钟和大dt保护；旧cancel/release不能解除新owner。
3. **确定性回放和诊断**：使用DS结构fixture、缺能力fixture和固定输入时间序列，输出当前控制来源、范围限制与降级理由，证明取消/复位后不残留。

关键验收：非对称范围与反向映射遵守冻结语义；不存在/未确认/物理输出参数不误写；嘴部开合与嘴形分离；非语音表情张嘴不被一律清零；语音owner结束后的闭合/释放策略明确；眼睑与眨眼组合不互相覆盖；无NaN/越界；同输入可回放。尚未写Core，故不能把这些测试称为真实表情改善。

交付到待审即停止。**不接真实Core、不创建自然动作导演、不迁移旧预设/口型、不引入Soullink产品依赖**。这些依赖真实接线的工作等主控审查后再派。

## 5. Antigravity：独立设置窗口与公开偏好最小闭环

建议沿用当前gemini-3.8-flash-high。开工前核实官方CLI的实际工具权限和插件隔离；不绕过先前拒绝。若仍只能读写文件，合同必须明确“文件候选，由Codex测试/提交”，不能承诺主控离线后还能自行完成全部验收。需要人工认证或正式权限调整时停下交接。

建议允许范围：主控在窗口契约中逐文件列出的main窗口模块、preload入口、renderer窗口入口、`settings-v2`相关组件及本任务测试/报告。该任务独占必要公共窗口接线；Qoder不得改这些文件。package/lock/总台账仍由主控登记。

同一任务分成三个阶段，每阶段明确已做/未做：

1. **窗口生命周期**：独立设置窗口单实例，重复打开聚焦现有窗口；正常缩放/最小化/关闭和重开；桌宠手动最小化后由Windows任务栏恢复，普通宿主事件不得强抢焦点。设置关闭不关闭桌宠，应用退出清理两窗。Windows可能合并任务栏图标，不承诺强制独立图标。
2. **有限的真实设置页**：沿用Bento，先按领域呈现已接入的十二个公开偏好；同一主进程存储作为唯一权威，每窗口只有视图/草稿。未接入的后端配置、密钥、语音试听、工坊不伪装成可用新功能，保留可到达的既有入口。
3. **保存与失败闭环**：加载、未保存、保存中、成功、失败、冲突都有清晰反馈；失败保留草稿，支持明确重试或放弃；冲突展示新快照并让用户确认，不能暗中重试覆盖另一窗口。重开状态来自权威存储。

关键验收：主进程登记两个真实窗口及各自准确页面，不能为新窗口放宽到任意同origin页面；跨窗口保存/冲突、关闭重开、键盘焦点/IME、窄窗/深浅色、最小化恢复与退出；设置窗口不新建模型/宿主/音频实例，不逐帧IPC传模型数据。

交付到待审即停止。**不在本任务自动迁移真实旧来源，不推广stable，不重做六领域全部表单**。完整语音页需要完整非敏感设置与安全凭据接口，不能拿十二字段的ttsProvider/ttsRate/ttsVolume直接充当完整TTS配置方案。

## 6. Codex额度耗尽时的交接

- 任务在开工前已实际投递、合同明确时，两个外部CLI可继续自己的有界任务；不依赖主控每隔几分钟回复。
- 同一任务内部按上述阶段推进，遵守同一合同；需要改接口、改其他任务文件或扩大功能范围时停止。没有预先批准的后续任务栈，不能自行找下一项工作。
- 正常完成后写result/progress、测试命令/实际退出码/未验GUI与进程现场。Antigravity若受命令权限限制，明确只交文件，保留现场。
- Codex回来前所有交付停在待审；无人自行合main、换正式数据、更新stable或发布ZIP。
- 当前持久runner尚未实现，不能把聊天监听当作离线调度器。下一批若需要监听需单独启用；第三批监听已关闭，不自动复用。

本批只安排两项开发任务。剩余额度不足时优先把合同与投递完成，验收留待恢复；比让两边依赖未冻结接口继续扩展更容易保持进度。
