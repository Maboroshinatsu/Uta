## 目标与范围

1. **窗口生命周期**：
   - 独立设置窗口单实例控制：重复打开聚焦现有窗口。
   - 正常缩放、最小化、关闭和重开。
   - 桌宠手动最小化后可由 Windows 任务栏恢复，普通宿主事件不得强抢焦点。
   - 设置窗口关闭不退出桌宠，应用退出时清理两窗并等待写入落盘。
   - 主进程安全登记两个真实窗口（`mainWindow` 与 `settingsWindow`），严格校验 senderFrame 与准确页面，拒绝任意同 origin 伪造。
2. **有限的真实设置页**：
   - 沿用 Bento Box Grid 视觉风格与 `settings-v2` 组件库。
   - 对接十二个公开偏好字段，同一主进程存储作为唯一权威，每窗口只有视图/草稿。
   - 设置窗口绝对不新建模型/宿主/音频实例，不逐帧 IPC 传模型数据。
   - 未接入的后端配置、密钥、语音试听、工坊不伪装成可用新功能，保留原有入口。
3. **保存与失败闭环**：
   - 加载、未保存、保存中、成功、失败、冲突均有清晰反馈。
   - 失败保留草稿，支持明确重试或放弃。
   - 冲突展示新快照并让用户确认，不能暗中重试覆盖另一窗口。
   - 重开状态来自权威存储。
