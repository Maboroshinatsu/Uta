# Uta 宿主适配器接入与渲染优化交接记录

日期：2026-10-17（Asia/Shanghai）

## 1. 任务目标与背景
将原本为 MaiBot 编写的完整 Live2D 桌宠前端解耦为跨 AI Agent 宿主的独立角色伴侣应用 `Uta`。
采用统一本地 HTTP 回环桥架构（`127.0.0.1` 动态端口 + Bearer Token 鉴权），不仅保留 MaiBot 作为后端适配器，还支持后续接入 Codex、DeepSeek Harness 及未来的 AstrBot。

## 2. 本阶段完成工作（P1 ~ P3）

### [P1: 固定 Uta 源码基线与现有能力初始提交]（Commit `354a297`）
- 建立 `Uta` 独立代码仓库基线，清除 MaiBot 特定协议强耦合。
- 确立 `app/`（Electron 桌宠客户端）与 `plugin/`（轻量 MCP 工具包）分层架构。

### [P2: 同步 v1.0.8 渲染优化与通用预设至 Uta]（Commit `4f15a2a`）
- 同步 12 组通用状态预设与三次 S 型缓动曲线插值（`easeInOutCubic`），彻底消除面瘫与死鱼眼；
- 限制眼球安全极值在 `±0.25~0.28`，动作时长收拢为舒适黄金期（0.6s 过渡、1.0s 停留、2.0s 留白）；
- 同步墨水级边界收敛（`inkBounds`）、非破坏性模型发现比对（`normalizeModelKey`）与悬停淡化。

### [P3: 接入 MaiBot 宿主适配器与端点双向通信]（Commit `8dde3da`）
- **适配器实现**：新增 `app/src/renderer/services/adapters/maibot.ts`，实现契约 `HostAdapter`：
  - 声明宿主能力：`sendInput: true`、`statusEvents: true`、`assistantText: true`、`characterTools: true`；
  - 周期健康探测：定时轮询 MaiBot 插件 Webhook 端点 `GET http://127.0.0.1:8524/health`，自动刷新连接状态；
  - 反向输入投递：气泡用户文本投递至 `POST /input/text`，窗口截图投递至 `POST /input/screenshot`，模型表情与控制同步至 `POST /sync/model`；
- **宿主注册表启用**：`app/src/renderer/services/adapters/index.ts` 将 MaiBot 标记为可用；
- **设置面板 UI**：`app/src/renderer/components/SettingsPanel.vue` 第 4 节增加宿主切换 Chips（Codex / MaiBot 一键切换）与通信通道状态反馈；
- **单元测试**：新增 `app/tests/adapters-maibot.test.cjs`，5 项单测覆盖元数据、健康探测、反向指令与模型同步；
- **测试通过**：`Uta/app` 94/94 项单测全绿，16/16 MCP 插件测试全绿，类型检查与 Electron-Vite 生产构建通过。
