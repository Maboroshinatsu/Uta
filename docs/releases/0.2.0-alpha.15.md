# Uta 0.2.0-alpha.15 体验说明

这一版修掉快捷面板的两个日常手感问题，并把桌宠回复气泡留得更久，避免消息一闪而过。

**首次体验请双击 `Try-Uta.bat`。** 它使用独立体验数据，不读取或修改日常 Uta 的数据。直接打开 `Uta.exe` 会使用日常数据，尚未验收前请不要用它替换旧版。

## 快捷面板

- **双击不再关闭面板**：在快捷面板里快速点两下，无论点在标题、模型、部件还是空白处，面板都会保持打开；面板内的双击属于面板自己，不会再触发桌宠窗口的“关面板 / 开输入框”行为。
- **模型变成独立大块**：原来的“角色”改名为“模型”，从和其他项一样的一行改成一张单独的卡片，显示“模型”和当前模型名；点卡片才展开 Live2D / 静态立绘和模型列表。标题栏下的分隔线保留。
- 宿主切换、部件保持、外观和桌面开关仍在原来的位置。

## 桌宠消息

- 确认 Qoder 的 hook 已连接到当前桌宠，状态和回复指令都能到达；本机测试回合的最终回复确实进入了消息记录。
- 回复气泡的**最短停留时间从约 3 秒延长到 5 秒**，较长回复按字数继续延长，最多 16 秒，减少“刚好没看到”的情况。
- 消息记录里保留完整历史；如果气泡已经消失，点侧边的“消息记录”仍能看到最近回复。

## 自动验证

应用 **907 项（902 通过、5 跳过、0 失败）**，插件 **105/105**，node/web 类型检查和构建通过。新增/更新回归覆盖面板双击不穿透、模型卡片结构与命名、气泡停留时间下限。

真实 Electron 隔离实例验证了：模型卡片显示、在面板内双击后仍保持打开；开发实例收到本机回复事件时气泡正常显示；通过 Qoder 的 Stop hook 发送的最终回复实际进入了消息记录。打包实例仍使用默认角色正常启动。

## 数据与回退

日常数据仍在 Windows 用户数据目录的 uta 文件夹。候选体验数据在 `%LOCALAPPDATA%\Uta-Candidates\0.2.0-alpha.15`；`Pets` 启动器使用 `%LOCALAPPDATA%\Uta-Pets\<平台>`，和候选/日常数据分开。

结束使用请右键托盘图标选择“退出”。需要退回旧版时，先退出此候选，再启动保留的旧 Uta；不要为了回退删除数据文件。

## 已知限制

- Qoder 只在**回合结束**时发送最终回复摘要；工作过程中是否出现模型主动发言，仍取决于模型是否调用 `deskpet_notify`。本轮没有把 Qoder 的全部助手正文自动转发到桌宠。
- 当前安装的 Qoder 插件仍是旧版本；如果后续更新了插件，行为以新插件为准。
- 锁定穿透、真实 Qoder 插件切换后的重连、真实 DSH 桌面安装、真实麦克风/云端 TTS、8 小时/7 天、多屏 DPI、恢复页标题栏和贴靠图标同步仍未验收。
- 本候选未替换日常 0.1.1/stable，也未配置代码签名。
