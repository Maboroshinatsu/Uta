# Uta 0.2.0 稳定版说明

这一版把 10 月底的宿主适配、模型导入和日常使用收在一起，作为 0.2 系列的第一个稳定版。

**解压后双击 `Uta.exe`。** 不需要安装 Node、Python 或 MaiBot 才能使用桌宠。单独解压仍会读取同一份日常数据，试用时应使用独立的数据目录。当前 ZIP 使用方法见 [启动 Uta](ZIP-FIRST-READ.md)。

## 这版重点

- **宿主接入**：DeepSeek Harness、Codex、Claude Code、Qoder、Antigravity、ZCode、OpenCode 都有对应的插件/MCP/hook 接入；支持工作状态、审批卡、会话目标、待办镜像和可用的反向输入。Qoder CLI 与 OpenCode 原生队列属于需要时再使用的通道。
- **模型导入**：角色设置里可以导入文件夹或 ZIP，先预览再保存；同名模型需要明确确认替换，保存失败会回滚，不会半覆盖原角色。
- **动作与外观**：预设工坊、多步动作、部件保持、静态立绘/Live2D 切换、模型校准和主题外观都保留；DSH 不再注入默认 RP 人设、称呼或 `[uta:…]` 神态标签指令。
- **日常使用**：待办/日常提醒、语音输入与朗读、快捷设置、聊天记录长历史渲染、崩溃重载和设置失败重试都已收口。
- **稳定性**：最新构建全量应用 1153 项（1147 通过、6 跳过、0 失败），插件 124/124 通过；空闲采样约单核 8.5%、工作集约 460MB，未发现前端错误。

## 包含内容

- 普通 ZIP 包含 Hiyori 与静态示例。DS 模型仅随指定分享包提供。
- Codex、Claude Code、DeepSeek Harness、Qoder、Antigravity、ZCode 的插件资源和 OpenCode 原生插件。
- MaiBot 适配器说明与所需文件。
- 首次使用引导、平台绑定、模型导入、待办、语音和完整设置中心。

分享包中的 DS 模型采用 CC BY-NC-SA 4.0。再分发请保留 `DS-MODEL-NOTICE.md` 与模型目录里的署名，并遵守非商业与相同方式共享条款。

## 已知限制

- 这是本地稳定构建，未做代码签名；Windows SmartScreen 的未知发布者提示属于预期现象。
- 真实 Codex/Claude/ZCode/Qoder/OpenCode/Antigravity 的安装、握手和精确续会话仍需要逐台机器验收；源码、假宿主和端到端探针通过不等于每个真实宿主都已验收。
- DSH 没有热重载：更新插件后要重启 DSH，并建议新开一个会话；旧会话可能还保留之前的称呼和标签习惯。
- 语音密钥、云端地址和个人数据不随包提供；真实账号、8 小时/7 天、多屏 DPI 和换机恢复需要自行验证。
