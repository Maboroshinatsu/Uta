# Uta 0.2.0-alpha.14 体验说明

这一版把小设置面板再理顺了一点：**宿主可以直接在面板里切换**，模型选择也从左上角的“品牌位”移到了正文，和“部件”一样成为一个正常分组。

**首次体验请双击 `Try-Uta.bat`。** 它使用独立体验数据，不读取或修改日常 Uta 的数据。直接打开 `Uta.exe` 会使用日常数据，尚未验收前请不要用它替换旧版。

## 小面板里切换宿主

- 面板新增“宿主”分组，显示当前连接的平台。展开后可以选 Antigravity、Qoder、Codex、Claude Code、ZCode、OpenCode、DeepSeek Harness。
- 这只桌宠仍然**一次只连接一个平台**。选择另一个平台后，会先出现一行确认：“当前平台会断开，桌宠会重新加载”。点“切换并重载”才会执行。
- 切换会更新这只桌宠的绑定，删掉旧平台留下的专属端点，然后重新加载桌宠窗口；模型、部件和已有设置不会丢。打开的设置窗口会同步显示新平台。
- 想彻底回到独立待机，仍然去“关于与诊断 → 解除平台绑定”，而不是在快捷面板里。

## 模型选择的位置

- 标题栏只保留“快捷设置”和关闭按钮，下面加了一条分隔线。
- 当前角色现在放在正文第一个“角色”分组里，和“部件”“宿主”采用同样的折叠样式；点一下才展开 Live2D / 静态立绘和模型列表。
- 模型名仍然直接显示在分组右侧，不会藏起来。

## 上一版的内容继续保留

单击与右键都切换表情，双击打开输入框；部件可以保持开启；Live2D 和静态立绘分别记住上次使用的角色；输入框只显示“输入消息…”。这些都在这一版里继续有效。

## 自动验证

应用 **907 项（902 通过、5 跳过、0 失败）**，插件 **105/105**，node/web 类型检查和构建通过。新增回归覆盖绑定切换、旧端点清理、面板宿主区和模型区位置。

真实 Electron 隔离实例验证了：面板标题分隔线、角色分组展开、宿主列表和内联确认；从“独立待机”切到 ZCode，再切到 OpenCode，再切回 ZCode；每次重载后当前角色仍是 DS；切走平台后旧端点文件被删除；设置窗口打开时从 OpenCode 切到 ZCode，连接页和平台绑定卡会即时变成 ZCode。

## 数据与回退

日常数据仍在 Windows 用户数据目录的 uta 文件夹。候选体验数据在 `%LOCALAPPDATA%\Uta-Candidates\0.2.0-alpha.14`；`Pets` 启动器使用 `%LOCALAPPDATA%\Uta-Pets\<平台>`，和候选/日常数据分开。

结束使用请右键托盘图标选择“退出”。需要退回旧版时，先退出此候选，再启动保留的旧 Uta；不要为了回退删除数据文件。

## 已知限制

- 本轮只真实切换了 ZCode / OpenCode，避免在本机同时运行 Qoder/Codex/Antigravity 时把它们的事件接走；真实插件连接到新宿主尚未验收。
- 切换宿主会重新加载桌宠，当前正在进行的对话会中断。这是有意的清理行为，不是静默切换。
- 快捷面板的宿主列表目前只列 agent 平台，不含独立运行和外部 HTTP 适配器；解除绑定仍在完整设置里。
- 真实 DSH 桌面安装、其他宿主真实会话、真实麦克风/云端 TTS、8 小时/7 天、多屏 DPI、恢复页标题栏和贴靠图标同步仍未验收。
- 本候选未替换日常 0.1.1/stable，也未配置代码签名。
