# Uta 0.2.0-alpha.16 体验说明

这一版让桌宠消息按 Markdown 正常显示，不再把 `**加粗**` 原样露出来。

**首次体验请双击 `Try-Uta.bat`。** 它使用独立体验数据，不读取或修改日常 Uta 的数据。直接打开 `Uta.exe` 会使用日常数据，尚未验收前请不要用它替换旧版。

## 气泡里的 Markdown

桌宠气泡和消息记录现在支持常见的 Markdown：

- **加粗**、*斜体*、~~删除线~~；
- `行内代码`；
- 代码块（保留换行，带独立底色）；
- 有序/无序列表、标题、引用和分隔线；
- `https://` 链接：消息记录里可点击，气泡里显示为链接样式。

所有内容都按纯文本 token 渲染，不使用 HTML 注入；宿主发来的 `<script>` 之类内容只会当普通文字显示。发送给语音的文本仍是清洗后的纯文本，不会念出星号或反引号。

## 为什么之前会露出星号

主进程之前把所有消息文本的换行都压成了空格，而加粗/斜体是行内格式，所以还能处理；列表、代码块和标题依赖换行，就完全看不出结构。现在消息正文（气泡、选择提示、最终回复）会保留换行，状态标签和工具名仍保持单行清洗。

## 自动验证

应用 **913 项（908 通过、5 跳过、0 失败）**，插件 **105/105**，node/web 类型检查和构建通过。新增 Markdown 解析与渲染回归，覆盖加粗、斜体、删除线、行内代码、代码块、列表、标题、引用、分隔线、链接白名单、未闭合标记和原始 HTML 文本化。

真实 Electron 隔离实例发送了一条包含加粗、斜体、列表和代码块的消息，气泡按格式显示，未见裸露的 `**`；消息记录也使用同一渲染。

## 数据与回退

日常数据仍在 Windows 用户数据目录的 uta 文件夹。候选体验数据在 `%LOCALAPPDATA%\Uta-Candidates\0.2.0-alpha.16`；`Pets` 启动器使用 `%LOCALAPPDATA%\Uta-Pets\<平台>`，和候选/日常数据分开。

结束使用请右键托盘图标选择“退出”。需要退回旧版时，先退出此候选，再启动保留的旧 Uta；不要为了回退删除数据文件。

## 已知限制

- Markdown 表格暂不排版成表格，会显示为普通文字；HTML 不解析。
- 链接只允许 `http/https`；浮动气泡里的链接不可点击，消息记录里可点击。
- 嵌套格式支持常见组合，但极复杂的 Markdown 会按普通文字降级。
- 真实 Qoder 插件更新后的行为、锁定穿透、真实宿主切换重连、真实 DSH/麦克风/云端 TTS、8 小时/7 天、多屏 DPI 仍未验收。
- 本候选未替换日常 0.1.1/stable，也未配置代码签名。
