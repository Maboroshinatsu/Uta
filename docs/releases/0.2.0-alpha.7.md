# Uta 0.2.0-alpha.7 体验说明

这是 alpha.3 之后的界面与首次使用候选版。重点是把“第一次打开 Uta”做成一条能看懂、能跳过、能重来的路，并把设置中心、快捷面板和预设工坊统一成一套安静的低饱和蓝色界面。

**首次体验请双击 `Try-Uta.bat`。** 它使用独立体验数据，不读取或修改日常 Uta 的数据。直接打开 `Uta.exe` 会使用日常数据，尚未验收前请不要用它替换旧版。

## alpha.7 修复

- 旧偏好导入不再列出已失效的悬浮球动作；静态立绘下视线跟随会禁用并说明原因。
- 修复角色页模型错误提示重复；Antigravity 的连接说明改为真实的工作区插件 + MCP 钩子。
- 候选/开发实例的托盘不再标出未注册的全局快捷键；稳定版按实际注册结果显示，并同步语音输入快捷键。
- 设置页“正在表现”会同步桌宠当前预设；悬停淡化的文案与实际透明度一致。

## alpha.6 修复

- 移除设置中心“桌面与交互”里已经失效的“角色身上的小圆点 / 快捷操作”卡片；桌宠面板当前不再显示这个圆点入口，保留旧偏好值只为兼容已有设置。

## alpha.5 修复

- 引导完成失败时不再困住流程：任何一步都可以“暂时退出，先进入设置”，之后从关于页重开，不用重新走一遍。
- 从语音步骤“前往语音设置”会先应用并保存已选的宿主与语音开关，不再丢掉刚做的选择。
- 安装或保存进行中会锁住步骤条、语音开关和跳转按钮，避免两个动作同时改状态。
- Codex 安装超时且进程没有确认退出时不再自动回滚配置；安装期间若配置被外部改过，会先另存当前版本再恢复；首次安装失败会移走本次新建的空配置；hooks 信任只在真正的 Uta hooks 段里判断。
- 最小窗口宽度下步骤条改为两列换行，不再隐藏最后一个步骤；任意强调色都会自动选择深色或浅色按钮文字，避免浅蓝配白字看不清。
- 预设工坊折叠标题里的“重置部件/归零”用键盘触发时不再连带折叠面板。

## 第一次打开

- 会自动出现首次引导：欢迎 → 连接宿主 → 选择角色 → 语音（可选）→ 开始使用。
- 每一步都可以跳过；退出后可以从“设置 → 关于与诊断 → 重新打开首次引导”回来，不会清空现有偏好或预设。
- 引导里的选择只在最后一步确认。没有验证过的阶段会写“等待中”，不会把没做到的事显示成成功。
- 语音默认关闭，引导里不会播放任何声音。

### 关于“安装并连接”

选择 Codex 后，可以在这里安装 Uta 的官方插件、桥接工具和 hooks。安装前会先备份 Codex 配置；如果备份失败或插件身份对不上，会停止安装并给出具体原因，不会假装恢复成功。安装完成后需要新开 Codex 会话，插件和 hooks 才会加载。

**注意：这一步会改本机 Codex 的真实配置（先备份），不是只改体验数据。** 如果你只想先看界面，选“跳过宿主连接”即可。DSH 的桌面 profile 由宿主独占，Uta 不自动改写，会在卡片里给出完整的手动步骤。Qoder、Antigravity、Claude Code、ZCode、OpenCode 本轮按手动或兼容方式展示。

## 界面与操作

- 设置中心、首次引导、快捷面板和预设工坊使用同一套暖纸色 + 低饱和蓝的设计；浅色和深色都按可读对比度复核。
- 设置窗口去掉了 Windows 自带标题栏，改为窗口内自绘标题栏：拖动、双击最大化、最小化、还原和关闭都在同一处，并会跟随窗口真实状态更新。
- 预设工坊的步骤改成纵向关键帧栈，宽屏下左边编排、右边调动作和部件；窄屏自动收成一列。
- 面板打开/收起、页面切换、选中反馈、加载和错误提示使用短而克制的动效。系统开启“减少动态”时会关闭持续漂浮和大部分过渡；窗口隐藏或最小化时暂停背景动画。
- 工坊、Live2D、口型和已有预设逻辑没有换引擎，仍是原来的真实功能。

## 数据与回退

日常数据保存在 Windows 用户数据目录的 uta 文件夹，不在解压目录。候选体验数据在 `%LOCALAPPDATA%\Uta-Candidates\0.2.0-alpha.7`，和日常数据分开。

结束使用请右键托盘图标选择“退出”。需要退回旧版时，先退出此候选，再启动保留的旧 Uta；不要为了回退删除数据文件。升级不会清空预设、密钥或设置；回退后旧版会忽略它不认识的新字段。

## 已知限制

- 本轮没有对你的真实 Codex 配置再次执行“安装并连接”；安装内核已有隔离环境与单元/冲突测试，但这个候选包的完整安装点击需要你在愿意接受备份时自行体验。
- 不随包附带 DS 鼠控版；需要把模型放进模型目录后选择。随附的示例立绘和 Hiyori 可用于基础体验。
- DSH 桌面 profile 必须手动安装；Qoder、Antigravity、Claude Code、ZCode、OpenCode 本轮没有做真实会话验收。
- 真实麦克风、真实云端 TTS 音色、人工听感、真实拔插显示器、外部宿主会话、8 小时连续运行和 7 天日常使用仍未验收。
- 恢复页的自绘标题栏、系统贴靠时的最大化图标同步、深色快捷面板只做了代码与尺寸检查，还没有逐项真实窗口验收。
- 本候选未替换日常 0.1.1/stable，也未配置代码签名。

## 来源与校验

ZIP 同目录的 `Uta-0.2.0-alpha.7-win-x64.zip.manifest.json` 记录源码提交、构建时间和 SHA-256；启动后“关于与诊断”也会显示版本和构建信息。发现问题时请保留体验数据，记录操作、提示和设置页显示的数据环境。
