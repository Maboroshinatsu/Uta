# Uta 0.3.0-beta.1

本版本为 Windows x64 预发布候选，正在进行本地验收，尚未公开发布。

## 本次更新

- 七种 Agent 宿主连接器，以及 MaiBot 和 AstrBot 聊天适配。
- 模型导入、状态预设、原生动作与部件编排，包含新版 Hiyori 默认预设。
- 统一设置页面、待办提醒、任务完成卡片和提示音。
- 全屏应用占用时自动隐藏，退出后恢复并补发到期提醒。
- 修复宿主路由、并行会话重复消息、回复目标、模型导入重试和待机恢复等问题。

## 安装与升级

完整解压普通 ZIP，双击 `Uta.exe`。想保留现有数据进行升级，退出旧程序后启动新程序；默认数据目录为 `%APPDATA%/uta`。需要独立体验时使用 `Try-Uta.bat`。请保留旧程序目录和数据备份。

宿主连接器随包提供，更新后需重开宿主会话。AstrBot 后端单独安装；本包附带 MaiBot 后端适配器。安装方式见 [宿主指南](../../plugin/HOST-INSTALL.md)。

## 已知限制

- 参数动作仍按共享节奏点分段过渡，复杂连续动作可能存在顿挫。
- 宿主未提供会话标题时会显示「未获取会话标题」。
- 部分宿主功能、独占全屏、多屏及长时间运行尚未完成最终包验收。
- Windows 下载提示与杀毒软件识别情况需要在实际下载后的环境核对；本地启动通过不等同于已签名。
