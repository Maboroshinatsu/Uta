# Uta 0.2.0-alpha.1 体验说明

这是新设置中心的早期体验版。建议先单独体验，不替换正在使用的日常版本。请完整解压 ZIP，再打开同目录的 Uta.exe；不要直接在压缩包里运行。

**首次体验请双击 `Try-Uta.bat`。** 它会使用独立体验数据，不读取或修改现有日常数据；同一份候选的后续体验会保留上次修改。这个入口不需要安装 Node 或开发工具。直接打开 Uta.exe 则默认使用日常数据，尚未验收前请不要用它替换旧版。

## 这次可以体验什么

- 设置使用独立窗口，默认进入“角色与动作”；六页分别是角色与动作、连接与会话、语音、桌面与交互、外观与性能、关于与诊断。桌宠保留托盘图标，右键托盘可以打开设置、显示桌宠或退出。
- 桌宠侧边的设置按钮打开快捷面板，可直接切换模型、日间/夜间、主题色和几个日常交互开关；底部进入完整设置。
- 主题、语音、桌面和播报偏好可保存。保存失败、外部修改冲突、未保存就关窗都有明确提示。
- 不会再强制显示旧设置升级页。旧页面记录保留在“关于与诊断 → 旧偏好导入”，只有逐项确认后才会写入当前偏好；模型、动作预设和密钥不参与这次导入。
- 无法读取新偏好时，可以查看备份、取消或确认恢复；较新版本的文件不会被降级覆盖。
- 语音页可试听本地或云端服务，显示合成、播放、停止或失败；语音服务需要自行配置。密钥只在明确保存时提交。
- 角色页能查看当前模型能力。支持时可短暂试用头部转动效果，也可随时停止；这不是完整的新动作系统。

## 数据与退出

默认日常数据保存在 Windows 用户数据目录的 uta 文件夹，不在解压目录。更换程序目录不会自动更换数据；复制程序也不等于备份设置。

设置顶部显示当前使用的数据环境。开发或隔离体验实例应显示自己的名称；看到“日常数据”时，修改会作用于日常数据。只需体验时请使用提供的独立体验启动入口。

关闭设置窗口不会退出桌宠。结束使用请右键托盘图标选择“退出”。需要退回旧程序时，先退出此版本，再启动保留的旧版；程序回退与偏好恢复是两件事，不要自行删除数据文件。

## 尚未完成

本候选没有把 DS 鼠控版设为随包默认模型；随附模型与素材条款见 THIRD_PARTY_LICENSES.md。完整的新 Live2D 表现、所有旧开发实例的设置导入、工坊与语音服务的统一草稿、全部宿主的实际兼容验证仍在开发中。

云端真实音色、麦克风、普通电脑上的完整兼容性和长时间运行仍需进一步验证。遇到问题先保留数据与旧程序，记录当时操作、错误提示和设置页显示的版本/数据环境。
