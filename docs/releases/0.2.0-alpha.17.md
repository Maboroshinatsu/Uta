# Uta 0.2.0-alpha.17 分享体验说明

这一版把 Uta 和 MaiBot 接了起来，并在分享包里带上 DS 鼠控版与 Hiyori 两套模型。

**这是一个给朋友试用的分享包。** 解压后双击 `Uta.exe` 就能看到桌宠，不需要安装 Node、Python 或 MaiBot。只有在使用 MaiBot 时，才需要另外放入随包适配器。

## MaiBot 适配器

现在可以把 Uta 当成 MaiBot 的一个桌面私聊窗口：

- 在 Uta 的气泡输入框里说话，MaiBot 会正常生成回复；
- MaiBot 处理时，桌宠进入“思考”状态；
- MaiBot 对这条私聊的回复会回到 Uta 气泡，并按 Uta 的语音设置朗读；
- MaiBot 在 QQ、微信等其他聊天里的回复不会进入 Uta，也不会被朗读。

首次引导里新增了“MaiBot 适配器”卡片。选择它并完成引导后，这只桌宠会固定绑定到 MaiBot。已经绑定其他平台的桌宠，需要先在“设置 → 关于与诊断”解除绑定，再重新进入引导。

适配器在 Uta 安装目录的 `resources\maibot-adapter` 里，安装方法见包内的 `MAIBOT-ADAPTER.md`。Uta 与 MaiBot 只通过本机 `127.0.0.1` 通信，不需要账号或密钥。

## 随包模型

- **DS 鼠控版**（`DS-control/c_0120`）：带完整表情、动作与控件，桌宠会使用 DS 专用自然编排。
- **Hiyori**（`hiyori_pro_zh`）：Live2D 官方示例模型，作为通用备选。

DS 模型的署名链是：上善无形「溟月」→ ZipZipPipe 女仆鲸鱼娘 → 氵六青 Live2D 化；参考项目 `Andersen216/dsh-whale-girl-live2d`。模型采用 CC BY-NC-SA 4.0（署名—非商业—相同方式共享）。本分享包经打包发起人确认已取得附带许可；如果你要再分发，请保留 `DS-MODEL-NOTICE.md` 与模型目录里的署名，遵守非商业与相同方式共享条款，商业使用需另行取得授权。

Hiyori 的使用受 Live2D 示例模型条款约束，详见包内 `THIRD_PARTY_LICENSES.md` 和模型目录中的原始说明。

## 数据与隐私

- ZIP 里不包含任何人的设置、聊天记录、语音密钥或宿主配置；首次启动是干净状态。
- Uta 的普通数据在 `%APPDATA%\uta`，卸载或换版本前请自行备份。
- 同一个数据目录不要同时启动多个 Uta 实例，否则运行时会互相抢占端点。

## 已知限制

- 这是未签名的 Windows x64 测试包。首次运行可能出现 SmartScreen 提示，需要选择“更多信息 → 仍要运行”。
- MaiBot 适配器已通过单元测试和本机模拟运行时测试；尚未在一套真实 MaiBot + QQ 账号上做端到端验收。首次使用时请先看 `MAIBOT-ADAPTER.md` 的排查步骤。
- 语音合成、语音识别需要使用者自己填写服务地址与密钥；分享包不附带任何密钥。
- 多屏 DPI、长时间连续运行、宿主升级兼容仍未覆盖。
- 本包不替换任何人的日常 Uta，也不会修改已有的 MaiBot 配置；适配器需要手动放进 MaiBot 的插件目录。
