# Uta 0.2.0-alpha.3 体验说明

这是继 alpha.2 之后的候选版，重点补上连接引导、语音完整可用、工坊草稿保护与长期使用的基础可靠性。建议先单独体验，不替换正在使用的日常版本。

**首次体验请双击 `Try-Uta.bat`。** 它使用独立体验数据，不读取或修改现有日常数据；同一份候选的后续体验会保留上次修改。直接打开 Uta.exe 会使用日常数据，尚未验收前请不要用它替换旧版。

## 这次可以体验什么

### 连接宿主

- “连接与会话”现在会一步步引导：选择平台、检查连接器和程序路径、选择会话、发送一条本地测试回复。
- 能看见“离线、未绑定、宿主不支持”等状态；Codex 支持选择具体会话并记住，其他宿主按各自能力显示。
- 发送失败会保留输入草稿；不会把一条没送出去的话当成已经发送。

### 语音

- 本地/云端 TTS 可以配置、试听和停止；识别失败不会伪装成成功。
- 关闭设置时，如果输入框里还有没保存的 API 密钥，会明确提醒保存或放弃，不再静默丢失。
- 录音可以中途取消，取消后不会再把迟到的识别结果塞进输入框。
- 识别失败会留一条“重试/放弃”的提示，重试会复用刚才的录音。
- 录音过程中切换宿主或关闭窗口，会终止这次语音输入，不会串到别的会话。
- 快捷设置的“安静模式”会同时关闭空闲小动作和状态解说；回复播报仍按语音设置。

### 工坊与预设

- 预设工坊支持撤销/重做；编辑、预览、撤销、保存的流程可以直接走通。
- 关闭设置时，未保存的工坊草稿会参与提醒，可以选择保存后关闭、放弃或继续编辑。
- “用户预设”可以导出一个带版本号的 JSON 文件，也可以从文件导入；文件和角色绑定，换角色后不会互相混用。
- 只有你真正保存过的预设会被导出，内置预设不会被误当成用户作品。
- 切换模型时如果文件缺失或损坏，桌宠上会给出“打开模型目录 / 去设置里更换角色”的明确入口。
- 自拍、蛋包饭等场景动作结束后会自动收道具，不会把默认的手或姿势留在桌面上。

### 长期使用

- 设置窗口在小屏或高缩放下会自动收缩到工作区内；显示器拔插、缩放变化或电脑休眠唤醒后，桌宠和设置窗口会被拉回可见区域。
- 隐藏或最小化时会停止不必要的全局光标轮询；空闲时按设置的帧率降频。

## 数据与回退

日常数据保存在 Windows 用户数据目录的 uta 文件夹，不在解压目录。候选体验数据在 `%LOCALAPPDATA%\Uta-Candidates\0.2.0-alpha.3`，和日常数据分开。

结束使用请右键托盘图标选择“退出”。需要退回旧版时，先退出此候选，再启动保留的旧 Uta；不要为了回退删除数据文件。升级不会清空预设、密钥或设置；回退后旧版会忽略它不认识的新字段。

## 已知限制

- 不随包附带 DS 鼠控版；需要把模型放进模型目录后选择。随附的示例立绘和 Hiyori 可用于基础体验。
- 真实麦克风、云端 TTS 音色、外部宿主会话需要本机自行配置；本版验证过本地模拟服务和假麦克风链路，不等于所有电脑或服务都可用。
- 声明式 HTTP 适配器当前只放行本机回环地址；远程 HTTPS 适配器仍未开放。
- 宿主 CLI 需要在 `host-paths.json`、`UTA_*_EXE` 或 PATH 中能找到；不要使用 `.cmd`/`.bat` 作为宿主入口。
- 多屏和高缩放做了窗口回收与尺寸限制，但跨机器、8 小时连续运行和 7 天日常使用仍需要实际时间验收。
- DSH、Qoder、Antigravity 的真实连接只完成了基础能力检查，主流程验收仍以 Codex 为主。

## 来源与校验

ZIP 同目录的 `Uta-0.2.0-alpha.3-win-x64.zip.manifest.json` 记录源码提交、构建时间和 SHA-256；启动后“关于与诊断”也会显示版本和构建信息。发现问题时请保留体验数据，记录操作、提示和设置页显示的数据环境。
