# Uta 0.2.0-alpha.18 分享体验说明

这一版修好了 DeepSeek Harness（DSH）接入里最容易卡住的一步：检测不到 DSH 时，不再只能看着一条无法执行的 `dsh plugin ...` 命令停住。

**分享包解压后双击 `Uta.exe`。** 不需要安装 Node、Python 或 MaiBot 才能看桌宠；接 DSH 时才需要本机已经安装 DSH。

## DSH 现在可以一键注入

- 首次引导的 DSH 卡片新增“安装 Uta 插件”。点击后会先备份 DSH 的 desktop profile，再调用 DSH 自带的 CLI 安装插件，最后回读确认插件和 `node_modules` 链接都存在。
- **安装前必须完全退出 DSH**；DSH 运行中 Uta 不会改写它的配置。
- 安装失败会自动恢复 `package.json`、`cordis.patch.yml` 和锁文件；备份目录会显示在卡片上。
- 自动找不到 DSH 程序或数据目录时，可以直接点“选择 DSH 程序”或“选择 DSH 数据目录”，不需要手动编辑配置或设置环境变量。
- 如果 DSH 还没启动过，卡片会提示先打开一次 DSH，等它创建 `~/.dsh/profiles/desktop` 后再回来检测。
- 安装成功后需要重新打开 DSH，并新开一个会话；Uta 才会收到 DSH 的状态和工具事件。

这次也支持常见的 DSH 安装位置（用户目录的 Programs、Program Files、原来的 `D:/DeepSeek-Harness`），并优先使用你手动选择过的路径。

## 仍然包含

- **MaiBot 适配器**：Uta 气泡私聊接入 MaiBot，回复流式回到桌宠；其他聊天平台的回复不会串进来。
- **DS 鼠控版**：完整表情、动作、控件，随包附带并保留模型署名。
- **Hiyori**：通用备选模型。

DS 模型采用 CC BY-NC-SA 4.0；本分享包经打包发起人确认已取得附带许可。再分发请保留 `DS-MODEL-NOTICE.md` 与模型目录里的署名，禁止商业使用，并遵守相同方式共享条款。

## 验证

- 应用 **939 项（934 通过、5 跳过、0 失败）**；MaiBot 适配器 17/17；node/web 类型检查与构建通过。
- 在真实 Electron 里用隔离的假 DSH 数据目录和 CLI 走完了“检测 → 安装 → 备份 → 回读 → 重启提示”全流程；真实 `~/.dsh` 配置未被改动。
- 真实 DSH 自带的 CLI 只跑了只读的 `plugin list`，没有在你的日常 DSH profile 上执行安装写入。

## 已知限制

- 没有在一套真实的 DSH 日常 profile 上执行最终安装；朋友第一次点“安装 Uta 插件”才是真实端到端。装完要重启 DSH。
- 包未签名；Windows SmartScreen 提示是测试包预期现象。
- 真实 MaiBot + QQ 账号端到端仍未验收；详见 `MAIBOT-ADAPTER.md`。
- 语音合成/识别密钥不随包提供；8 小时/7 天、多屏 DPI 仍未覆盖。
