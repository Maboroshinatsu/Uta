# Uta 0.2.0-alpha.13 体验说明

这一版把日常操作往“少点开一层”收紧：工作状态直接复用你已有的聆听/工作动作，快捷面板可以展开模型、直接开关部件，左右键点击也不再各做一套。模型的显示模式切换会分别记住上次选择。

**首次体验请双击 `Try-Uta.bat`。** 它使用独立体验数据，不读取或修改日常 Uta 的数据。直接打开 `Uta.exe` 会使用日常数据，尚未验收前请不要用它替换旧版。

## 工作中不再监听输入框

宿主应用没有向桌宠提供“输入框获得焦点”的事件，所以这一版不再假装监听宿主输入框。桌宠进入思考或执行工具时，会按以下顺序选择工作动作：

1. 你创建的“聆听记录”预设；
2. “聆听”；
3. “工作”；
4. 最后才回退到“思考”“专注”或“好奇”。

有一项可用就会循环播放，不会因为工作解说或工具切换反复跳走。桌宠自己的输入框也不再触发聆听动作。

## 点击与表情

- 在模型上**单击**和**右键**现在是同一件事：切换到下一个表情。不会再单独弹“戳一戳”台词。
- **双击**仍然打开桌宠输入框；单击不会误开输入框。
- 单击加入约 0.2 秒延迟，确保双击时不会先换一次表情。
- 输入框只保留“输入消息…”占位提示，不再重复解释发送方式。

## 快捷面板

- 顶部显示当前角色，点一下才展开模型列表，面板默认更紧凑。
- 去掉了主题色圆点；需要改强调色时进完整设置。
- “桌面”里新增**锁定穿透**。开启后鼠标会直接穿过桌宠；按 `Ctrl+Alt+L` 或从托盘菜单解除。
- 新增**部件**折叠区：按服装配饰、发型发饰、手部与道具、脸部特效、其他开关分组，直接开关工坊里的模型控件，不必先进入预设工坊。
- 从快捷面板开启的部件会**保持**：待机清理、预设动作和普通工作动作都不会把它关掉；如果它与某个预设冲突，以你保持的部件为准。
- 部件区底部有“关闭全部保持部件”，一次释放所有手动保持的部件。

## 模型记忆

Live2D 和静态立绘现在分别记住上次使用的角色。切到静态立绘再切回 Live2D，会回到之前的 Live2D 模型；再切到静态立绘，也会回到之前的立绘包，而不是每次挑列表第一项。

## 自动验证

应用 **903 项（898 通过、5 跳过、0 失败）**，插件 **105/105**，node/web 类型检查和构建通过。真实 Electron 隔离实例验证了：模型折叠菜单、部件开关与“保持”标记、双击打开输入框、单击不开输入框、DS ↔ 静态立绘往返记忆、快捷面板紧凑展开，以及从宿主事件进入工作状态时设置页显示“正在表现 工作·连续”。

## 数据与回退

日常数据仍在 Windows 用户数据目录的 uta 文件夹。候选体验数据在 `%LOCALAPPDATA%\Uta-Candidates\0.2.0-alpha.13`；`Pets` 启动器使用 `%LOCALAPPDATA%\Uta-Pets\<平台>`，和候选/日常数据分开。

结束使用请右键托盘图标选择“退出”。需要退回旧版时，先退出此候选，再启动保留的旧 Uta；不要为了回退删除数据文件。

## 已知限制

- 锁定穿透本轮只做了代码与回归验证，没有在真实双实例环境下点击开启/解除，避免影响正在运行的旧实例与全局快捷键。
- 工作动作的真实画面使用隔离开发实例和一条手工宿主事件验证；没有连接你的日常宿主配置。
- 真实 DSH 桌面安装、其他宿主的真实会话、真实麦克风/云端 TTS、8 小时/7 天、多屏 DPI、恢复页标题栏和贴靠图标同步仍未验收。
- 本候选未替换日常 0.1.1/stable，也未配置代码签名。
