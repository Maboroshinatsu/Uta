# Uta 0.2.0-alpha.2 体验说明

这是面向日常体验的候选版，包含设置中心、DS 日常表现、语音配置修复和连接可靠性修复。建议先单独体验，不替换正在使用的日常版本。

**首次体验请双击 `Try-Uta.bat`。** 它使用独立体验数据，不读取或修改现有日常数据；同一份候选的后续体验会保留上次修改。直接打开 Uta.exe 会使用日常数据，尚未验收前请不要用它替换旧版。

## 这次可以体验什么

- 桌宠侧边的设置按钮打开快捷面板：切换模型、日间/夜间、主题色、悬停半透明、视线跟随和空闲小动作。
- 完整设置使用独立窗口，六页分别是角色与动作、连接与会话、语音、桌面与交互、外观与性能、关于与诊断。
- 角色与动作页可以切换 Live2D/静态立绘、试听动作、编辑预设；支持安全原生动作和工坊临时部件恢复。
- 连接与会话可以查看当前宿主、切换平台、重新连接；外部声明式适配器会显示在平台列表里。
- 语音页可以配置本地/云端 TTS、试听、保存密钥和语音输入；服务失败会明确显示，不会伪装成功。
- 主题、语音、桌面和播报偏好会保存；保存失败和外部修改冲突有提示。旧页面偏好可在“关于与诊断 → 旧偏好导入”里逐项确认导入，不会强制升级。
- 本次修复了发送失败覆盖新草稿、批处理宿主入口、Runtime 并发同序号、云端 TTS 换域名沿用旧密钥和跨域重定向认证泄露等问题。

## 数据与回退

日常数据保存在 Windows 用户数据目录的 uta 文件夹，不在解压目录。更换程序文件夹不会自动更换数据；复制程序也不等于备份设置。

候选体验数据在 `%LOCALAPPDATA%\Uta-Candidates\0.2.0-alpha.2`，和日常数据分开。结束使用请右键托盘图标选择“退出”。需要退回旧版时，先退出此候选，再启动保留的旧 Uta；不要为了回退删除数据文件。

## 已知限制

- 不随包附带 DS 鼠控版；需要把模型放进模型目录后选择。随附的示例立绘和 Hiyori 可用于基础体验。
- 真实麦克风、云端 TTS 音色、外部宿主会话需要本机自行配置；验证记录不等于所有电脑或服务都可用。
- 声明式 HTTP 适配器当前只放行本机回环地址；远程 HTTPS 适配器仍未开放。
- 宿主 CLI 需要在 `host-paths.json`、`UTA_*_EXE` 或 PATH 中能找到；不要使用 `.cmd`/`.bat` 作为宿主入口。
- 跨机器安装路径、长时间运行、多屏/高缩放和完整无障碍仍需后续验收。密钥和工坊草稿还没有统一的关闭保护提示。

## 来源与校验

ZIP 同目录的 `Uta-0.2.0-alpha.2-win-x64.zip.manifest.json` 记录源码提交、构建时间和 SHA-256；启动后“关于与诊断”也会显示版本和构建信息。发现问题时请保留体验数据，记录操作、提示和设置页显示的数据环境。
