# Uta 0.2.0-alpha.11 体验说明

这是 alpha.10 的复审修复版。重点不是新增功能，而是把“你以为已经保存、其实被静默丢掉”和“界面说成功、实际还没完成”的地方补齐。

**首次体验请双击 `Try-Uta.bat`。** 它使用独立体验数据，不读取或修改日常 Uta 的数据。直接打开 `Uta.exe` 会使用日常数据，尚未验收前请不要用它替换旧版。

## alpha.11 修复

### 安装与首次引导

- 安装 Codex 插件超时、且 Codex 进程没有确认退出时，Uta 会暂停后续安装写入，不允许连续重试再开一个写配置的进程。完全退出 Codex 后，可以在卡片上点“已退出 Codex，解除安装阻断”再重试。
- 重开首次引导前，如果语音密钥或预设工坊还有没保存的内容，会先问“保存 / 放弃 / 继续编辑”，不再因为切换页面把草稿直接注销。
- 安装和检测会检查 Codex 的 Uta MCP 所需的 `node` 命令；找不到 Node.js 时会在写入配置前停止，不会出现插件装上了、工具却启动不了的假成功。
- “工具”阶段不再只看列表里有没有一个相似名字。只有精确匹配到 `uta-deskpet` 且启用时才继续；已登记也不直接显示绿色“已验证”，会明确写“新会话握手后才能确认”。
- Qoder、Antigravity、Claude Code、ZCode、OpenCode 的手动步骤改成随包可执行的材料，安装包内直接带对应 ZIP、市场目录或单文件插件。Qoder/Antigravity 会写“本版暂不支持自动检测”，不再写成“未检测到”。

### 角色与预设工坊

- 工坊有未保存草稿时换角色，会先问“保存草稿并换角色 / 放弃草稿并换角色 / 继续编辑”。从桌宠快捷面板换角色时，如果设置窗口里还有未保存的工坊草稿，会直接拦住并提示先去保存，不再静默清空草稿和撤销历史。
- 工坊的撤销/重做会完整保留“循环播放”，不再把循环预设悄悄改成播完恢复。
- 切换到静态立绘时，会等新立绘真正挂载完成再回报结果；不会出现画面已经切过去、界面却说“模型加载失败”。切换失败才会报失败。

### 连接与运行时

- 切换宿主时，上一个宿主迟到的会话列表或选择结果会被丢弃；列表、固定会话和加载状态会先清干净，不再把 Codex 的旧会话显示到 DeepSeek Harness 下。
- 同一个运行时事件正在投递时，重复请求会等第一次的结果；只有第一次已经成功投递，重复请求才会收到“已处理”。第一次失败时，重复请求也会收到失败，不会提前报成功。
- 强调色文字改用同一套对比度计算。内置“琥珀暖棕”等中等亮度主题不再出现白字看不清；悬停底色会按文字明暗方向调整，正常和悬停状态都保持可读。

## alpha.10 修复

- 切回“日常待机”时，不再在预设过渡中途硬复位场景参数，避免校服/部件回默认时有概率闪烁。
- 工坊里取消一个已选部件时，残留参数清理会等 600ms 过渡结束，不再把刚启动的淡出直接打断。

## 第一次打开

- 会自动出现首次引导：欢迎 → 连接宿主 → 选择角色 → 语音（可选）→ 开始使用。
- 每一步都可以跳过；退出后可以从“设置 → 关于与诊断 → 重新打开首次引导”回来。现在重开前会先保护未保存的草稿。
- 语音默认关闭，引导里不会播放任何声音。

### 关于“安装并连接”

Codex 可以在引导里自动安装官方插件、桥接工具和 hooks。安装前会备份 Codex 配置；安装超时且进程未退出时会保持阻断，避免两个进程同时写配置。DSH 的桌面 profile 由宿主独占，Uta 不自动改写，会在卡片里给出完整手动步骤。

**注意：自动安装会改本机 Codex 的真实配置（先备份），不是只改体验数据。** 如果只想先看界面，选“跳过宿主连接”即可。其它宿主的材料现在随包提供，首次引导卡片里会给出直接可用的路径。

## 界面与操作

- 设置中心、首次引导、快捷面板和预设工坊继续使用暖纸色 + 低饱和蓝的设计；浅色和深色主题共用同一套强调色对比度算法。
- 设置窗口使用窗口内自绘标题栏：拖动、双击最大化、最小化、还原和关闭都在同一处。
- 预设工坊的步骤是纵向关键帧栈，宽屏下左边编排、右边调动作和部件；窄屏自动收成一列。
- 面板打开/收起、页面切换、选中反馈、加载和错误提示使用短而克制的动效；系统开启“减少动态”时会关闭持续漂浮和大部分过渡。
- 工坊、Live2D、口型和已有预设逻辑没有换引擎，仍是原来的真实功能。

## 数据与回退

日常数据保存在 Windows 用户数据目录的 uta 文件夹，不在解压目录。候选体验数据在 `%LOCALAPPDATA%\Uta-Candidates\0.2.0-alpha.11`，和日常数据分开。

结束使用请右键托盘图标选择“退出”。需要退回旧版时，先退出此候选，再启动保留的旧 Uta；不要为了回退删除数据文件。升级不会清空预设、密钥或设置；回退后旧版会忽略它不认识的新字段。

## 已知限制

- 本轮没有对你的真实 Codex 配置执行“安装并连接”；安装互斥、Node 检查、MCP 状态解析和超时恢复已有隔离测试，但完整安装点击需要你在愿意接受备份时自行体验。
- 不随包附带 DS 鼠控版；需要把模型放进模型目录后选择。随附的示例立绘和 Hiyori 可用于基础体验。
- DSH 桌面 profile 必须手动安装；Qoder、Antigravity、Claude Code、ZCode、OpenCode 的真实会话仍未逐项验收。
- 静态立绘与会话竞态的修复有真实组件脚本和受控回环测试；本轮仍需要真实窗口里用你常用的模型再确认一次。
- 真实麦克风、真实云端 TTS 音色、人工听感、真实拔插显示器、外部宿主会话、8 小时连续运行和 7 天日常使用仍未验收。
- 恢复页的自绘标题栏、系统贴靠时的最大化图标同步、深色快捷面板只做了代码与尺寸检查，还没有逐项真实窗口验收。
- 复审报告里关于默认窗口动作栈位置、关键帧 DOM 身份和 `.pressable` 回弹时长的界面建议，本轮没有改动；它们不影响上面这些数据与状态修复。
- 本候选未替换日常 0.1.1/stable，也未配置代码签名。
