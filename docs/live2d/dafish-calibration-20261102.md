# 大肥鱼参数标定：2026-11-02

这是给后续动作调试使用的实测记录，不是模型参数名的推测，也不代表已完成全部状态预设设计。

模型资源签名：`uta-live2d-assets-v1:b72fb6bc0c74e119b0f11db582d90e6736bc3471226b10085e48c4dbb0583fe8`。模型更新后先复查签名和关键实验，不能照搬结论到其他 Live2D 模型。

## 覆盖与证据

- 509 个真实参数：292 个物理输出、25 个 Divider、5 个服装开关、2 个标记参数，本轮剩余 **185 个候选输入全部做过初筛**。额外对 3 个物理输出做前后阶段写入对照。
- 第一批共 387 次截图实验：primary 84、arms 58、secondary 141、paths-face 51、clean-confirm 33、face-physics 20。初筛不等于每个参数均已完成条件组合、幅度和动态验收。
- 本机原始证据在 `D:/Frankenstein/Uta-Workspace/runtime/previews/dafish-calibration-20261102/`；各实验 results.json 保存请求、物理前输入和渲染前实际值，PNG 保存画面。trial-index.json 汇总每次参数请求，不含宿主凭据。
- 先比较三个重复基线，再进行单变量和条件变量实验。首轮基线像素差（每通道差 >20）为 0/76/78，回归为 47；清理无关输入和 UI 后的重复/回归基线均为 0。
- secondary 的后半段、paths-face 最后帧混入了自动气泡。其整图计数只作初筛，不能用于确认参数生效；后续隐藏气泡并冻结无关输入复测。嘴形等小范围细节必须放大看原图，不能以全身像素阈值判“无效”。
- `mode: input` 在物理前写入，保留正式链路后续修改，用于识别覆盖；`mode: output` 在物理后直接写入，只能证明底层形变，不证明正式播放器能够驱动。最终动作须回到无试验钩子的实例验收。

## 身体：已确认的控制入口

| 输入 | 实测 | 后果与使用方式 |
| --- | --- | --- |
| AngleX/Y/Z | 各 ±12，画面与实际值均有响应 | 头部角度输入，经物理后驱动 ParamAngleX/Y/Z；不要直接写后者 |
| PositionX | ±12 | 驱动躯干 X；+12 时 ParamBodyAngleX 约 +12。适合让身体晚于头部转向 |
| PositionY | ±12 | 躯干纵向响应，正负增益不对称；不宜把正负值视作等幅动作 |
| PositionZ | ±12 | 身体与骨盆反向联动；+12 时 ParamBodyAngleZ 约 -8.4、HipAngleZ 约 +6.74，适合小幅重心变化 |
| LeanInput | ±12 | 身体俯仰/前倾输入；+12 时 ParamBodyAngleY 约 +25.62，-12 时约 -8.82。幅度应保守 |
| ParamBreath | 0.35/1 | 明显带动躯干；正式 SDK 自带呼吸还会参与，试片未另加此轨道 |
| ParamAngleX、ParamBodyAngleX/Z | 物理前 +12 / 物理后 +12 对照 | 前写被覆盖、几乎无画面变化，后写则明显改变形变；属于物理输出，不作为独立动作入口 |
| ShoulderYy、HipAngleXq、ParamBodyAngleRY/RZ 等 | ±12 单变量 | 当前姿态未观察到明显变化，不能仅凭名称使用，也不能宣布所有上下文下均无效 |

## 手部：需要开关与关节共同编排

Movement1/2/3 是不同手/道具选择，不会替我们完成自然的起收手。手型显隐发生在手臂已经抬起时，会产生两套手臂重叠的过渡画面；试片把切换安排在关节归零时。

| 参数 | 实测上下文 | 已观察到的影响 |
| --- | --- | --- |
| Movement1 | 0.35/1 | 狗尾草与对应右手显隐 |
| Movement2 | 0/0.15/0.35/0.5/0.75/1 | 抚胸手显隐；关节不编排时手仍在下方，中间值会出现两套手混合 |
| Movement3 | 0.35/1 | 食指手显隐 |
| Param62 | Movement2=1，其余保持抚胸参考姿态；-.6/-.25/.25/.6 | 左上臂角度；正大值使上臂明显外展，负值使肘更靠内 |
| Param59 | 同上，四档 | 左上臂透视/位置变化，不能与肘角同一比例线性推进 |
| Param60 | 同上，四档 | 左前臂角度，影响手的弧线路径；正向中段容易先向外展开 |
| Param61 | 同上，四档 | 小范围手腕转动；与同姿态 reference 比较有约 1000–1600 个变化像素，不能用“相对垂手总差”评估腕部影响 |
| Param36/39/41/42 | 食指手参考姿态，四档 | 对应右上臂/透视/前臂/腕部均有画面变化 |
| Param43 | 同上，四档 | 食指细节变化较小，需手部近景检查 |
| Param55/56/57/58 | 物理前后分别试写 1 | Uta base 会将前写覆盖为 0；后写仅轻微变化。chest/input 与 chest/output 的手姿相同，不能继续假定这些是抚胸所必需的开关；新试片不驱动这些照明参数 |

抚胸参考姿态约为 `Movement2=1, Param62=.034, Param59=.476, Param60=.86, Param61=0`。这是一个姿态锚点，不是动作轨迹。测试了三条正向抬手路径共 21 个采样姿态，以及更强向内收肩的 7 个姿态；均保留截图。继续调试时应根据中间姿态改路径，而不只是让终点更漂亮。

追加了 13 次 inward-path 试验（另一隔离实例，同一模型签名），总数为 **400 次**。发现 Param60 负向可使手经过腰前向内折；并非必须走正向外展。B 试片采用该路径前半段，胸前姿态约为 `Param62=.017, Param59=.119, Param60=-.692, Param61=0`。没有强行从 -1 跳到正 .86；两个端点不是同一姿态，不能为“角度绕圈”制造参数跳变。原正向 A 试片与 B 均保留，对照见 `Uta-Workspace/runtime/previews/dafish-calibrated-happy-20261102/`。

## 面部：区分直接形变、物理联动与播放层修改

| 参数 | 实测结论 |
| --- | --- |
| ParamMouthForm | -1..1 放大图可见嘴角变化，但形变区域很小；小像素计数不能判无效。普通 input 后还可能被 ambient 改值，正式动作需要声明参数所有权 |
| ParamMouthOpenY | 0.1..1 可从微张口变为圆形张口；轻笑试片用约 .27，避免大幅圆嘴变成惊讶 |
| EyeSmile | 单独改变时影响细小；与眼开度 .45/.75 的组合能看到眼形变化。只记录条件性效果，不把它当成一条必然产生笑眼的通用轨道 |
| ParamEyeLOpen/ROpen | 可驱动眼睑，但压得太低容易看成困倦；只在笑的峰值短暂收窄，其余时间保持接近常态 |
| ParamEyeBallX/Y | 确实改变视线；ambient 可能叠加约 .04–.06，正式样板应让出所有权 |
| ParamBrowLY/RY | ±.7 可见眉形变化，试片只用小幅变化 |
| key7 | .25/.45 在本机截图差异很小，.65 明显；保留渐入渐出而非仅靠小数值宣称已脸红 |
| JawOpen | 当前单变量条件下影响很弱；新试片不靠它表达轻笑 |

`ParamEyeLSmile/ParamEyeRSmile` 在这份真实清单中不存在，不能沿用通用模型假设。发丝、裙摆与尾部的 292 个物理输出不作为本轮主动编排对象，让它们跟随身体输入响应。

## 尚未证明的内容

初筛中大部分特效/辅助输入在当前服饰与部件上下文下没有明显响应，不等于它们永远无效。没有测试 5 个服装开关，也没有强写每个物理输出。由动态气泡污染的 secondary 整图计数不进入“已生效”名单。最终动作自然程度仍需看真实连续播放与用户反馈，参数合法、像素发生变化和观感好是三个不同结论。

## 用户否定 V3 与本轮修正

用户反馈 V3 效果特别差，幅度几乎不可察觉、动作极慢、未看到头以外的身体动作。此前的参数生效实验不能推出最终编排观感合格：V3身体输入的主要峰值仅1–3，主要手势抬起2.1秒、放下3.7秒，节奏与幅度都失当。

新增V4「开心·身体主导样板」，6.4秒，保留V1/V2/V3对照。身体主输入PositionX峰12、PositionZ峰16、PositionY峰6.5；抬手.24→.98秒（.74秒），收手2.12→3.12秒（1秒）。先以头部三输入全零做正常SDK播放对照，再加入小幅头部配合。

另定位并修复视线关闭仍把全身画布中心作为跟随目标的错误：真正中立应是focusController的(0,0)偏移。错误会造成AngleY/PositionY达到-30，掩盖动作开头。仅写旧localStorage键也没有真正关闭规范设置中的视线。已用fresh隔离profile、运行时关闭gaze/idle确认，V4首步的视线接管缩到200ms。

最终头固定对照在物理/播放层之后读取的AngleX/Y/Z全为0；躯干X约-3.48..11.96、躯干Z约-12.68..3.16、骨盆Z约-2.30..9.73、腿Z约-4.18..16.33。对应证据在 `Uta-Workspace/runtime/previews/dafish-body-led-20261102/final/`。早先`head-still`和`head-still-clean`仍受旧视线偏移/旧步骤时长干扰，不能作为头固定成功证据；有效对照为final/body-with-head-fixed及final/head-fixed-trace.json。
