# 蓝调生息（Blue Biophilic）设计规范

来源：2026-10-25 用户提供的两张 Organic Biophilic 参考图。保留其自然曲率、低饱和混色、编辑式大标题和垂直动作栈；主色从参考图的苔绿替换为蓝，避免照搬绿色。

## 1. 气质

- 安静、有机、像纸与釉面，不像仪表盘。
- 大留白、低对比边界、柔和色块；重要操作才用饱和蓝。
- 形状来自鹅卵石与叶脉：没有尖锐直角，没有硬阴影。
- 动效解释层级和状态，不做持续炫技。

## 2. 色彩

配色规则：
- 一屏最多一个高饱和蓝按钮；其余用 `accent-soft` 或描边。
- 装饰色块只允许蓝、鼠尾草、沙色三种，透明度 12–30%。
- 不使用纯白大底配纯黑字；深色不使用纯黑。
- 文本对比度至少 4.5:1；大标题可用 ink。

## 3. 字体与排版

- 无衬线：系统 UI 字体；等宽只给数值和快捷键。
- 展示标题：34–44px，字重 750，字距 -0.03em，行高 1.02。
- 分区标题：18–20px，字重 700。
- 正文：13–14px，行高 1.55–1.65。
- 小标签：10.5–11px，大写/宽字距 0.08em，只给阶段名和字段名。
- 中文长文本允许换行，不用 `white-space: nowrap` 硬顶。

## 4. 形状与层次

- 圆角：小控件 10px，卡片 18px，大面板 24px，胶囊 999px。
- 边界：1px `line`；阴影只用 0 12px 32px rgba(28,42,49,.08)。
- 卡片之间用留白和底色分层，不套三层阴影。
- 装饰性有机形状仅用于引导页和空状态；设置页保持可扫描。

## 5. 关键组件

### 动作栈

参考图右侧的垂直堆叠：

- 每一步是一张整宽胶囊卡，编号 `STEP 01`、名称、过渡/停留时间。
- 选中项用 `accent` 实底白字；未选中用 `accent-soft` 或 surface。
- 步骤之间有 8–10px 间距和轻微重叠感，不做折角。
- 底部固定“+ 新增动作帧”暖色胶囊。
- 右侧或下方显示当前步骤的滑块/控件摘要；状态与真实工坊一致。

### 胶囊标签/按钮

- 高度 30–34px，左右 12–14px；选中蓝底白字，未选中纸色底。
- 不使用大面积描边按钮；主操作实底，次操作透明/微底。

### 输入与滑块

- 纸色内陷底，1px 线；焦点环 2px accent 30%。
- 数值用等宽字体，单位弱化。

## 6. 布局

- 宽屏：左 42% 编辑栏 + 右 58% 动作区，像参考图的海报结构。
- 中等：上下堆叠，标题缩到 30px。
- 窄窗：单列；动作栈保持整宽；按钮换行不截断。
- 引导页使用大标题 + 步骤胶囊 + 右侧状态卡；设置页沿用现有侧栏，不改成海报。

## 7. 动效

- 快速反馈 120–160ms；页面/抽屉 220–280ms；引导首屏 420ms。
- 曲线：`cubic-bezier(0.22, 1, 0.36, 1)`；退出比进入快 20%。
- 只动 `opacity` 和 `transform`；不动布局尺寸。
- 面板开合可被再次点击打断，以当前视觉状态为起点。
- `prefers-reduced-motion: reduce` 下位移和装饰漂移归零，只保留 1ms 状态切换。
- 隐藏/最小化时停止装饰动画和光标轮询。

## 8. 禁止

- 不用紫色渐变、玻璃拟态大面积模糊、霓虹发光。
- 不用每个卡片都不同的圆角或颜色。
- 不用表情符号代替图标。
- 不把测试成功当视觉验收。
