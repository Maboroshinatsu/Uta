本地文件：[settings-ux-wireframe.html](settings-ux-wireframe.html)。用普通浏览器打开即可，所有 CSS/JS 在单个文件内，不依赖网络或 npm。可与 [完整方案](settings-ux-proposal.md) 对照。线框是结构和关键交互演示，不是可直接打包的产品实现；示例角色、平台状态、地址、参数均非个人数据。

最新视觉方向已改为蓝色大色块，见 [规范](blue-block-design-spec.md)；旧截图只作历史流程证据，最新蓝色截图见 [本轮规划交付](../workflow/results/product-performance-plan.md)。产品代码与日常 exe 未变化。

参考资料吸收后已补充：模型/地址失焦校验、错误提示与输入保留、可选择失败/成功的本地模拟测试、失败重试、修改草稿隔离旧回调，以及桌宠最小化/恢复的文字示意。新增行为见 [参考吸收与窗口规则](settings-ux-reference-review.md)。模拟器的定时器仅驱动明确标注的演示，不代表真实服务进度或取消能力。

[本轮桌面布局示意截图](settings-ux-reference-preview.png)；页面中的最小化/恢复按钮只解释目标行为，不操作系统窗口。

## 建议评审顺序

1. 先看“角色与动作”：是否能分清当前角色、日常状态、播放与编辑。
2. 打开“连接与会话”：选 Codex/Qoder/Antigravity，对照本机服务、平台接入、会话与文本能力的不同含义。状态为示例，没有检测电脑。
3. 打开“语音”：默认只展示摘要，点击“配置服务”；先清空模型字段再测试，查看就地错误；填回模型，在“本地模拟结果”选择失败并测试，确认输入保留且仍未保存；改成模拟成功后重试。测试过程中修改字段，晚回包不能显示旧成功。全部为本地演示，不调用服务。
4. 搜索“穿透”：从结果跳到“桌面与交互”。演示搜索只定位页面；产品目标是定位具体设置字段。
5. 从角色页新建/编辑动作：选择步骤、增加步骤、修改参数、预览、保存；返回库时查看未保存守卫。保存不自动播放，预览不保存。
6. 顶部“快捷区”查看日常浮窗应保留的内容。试“窄窗口”和“深浅色”；较窄视口使用文字页面选择器。

## 演示范围

- 已接入：六页面导航、关键词到页面搜索、平台选择和示例能力说明、语音配置展开/字段校验/本地模拟等待与失败/重试/草稿标记/测试和保存的不同反馈、工坊步骤选择/新增、参数变化、预览状态、保存状态、离开草稿对话框与焦点约束、快捷区、窄布局和主题演示。
- 只给说明：更换真实模型、播放动作、平台检测、设备/音频、重置/恢复、另存为、完整撤销/重做。点击这些按钮只说明预期，不模拟真实成功。
- 未实现产品级数据能力：独立 provider 草稿、退出浏览器保护、跨重启草稿、revision 冲突、密钥、IPC、文件读写和真实错误重试。不要输入实际 API Key；页面也不会将输入传到网络或写入浏览器存储。
- 工坊的角色图形仅为位置示意，产品建议仍由已有桌宠舞台预览。宽屏三栏、小屏折叠为更少列；此线框并非已通过所有 DPI/屏幕的最终视觉稿。

本地预览仅用于评审；PID/端口/状态记录在仓库外 operations/settings-ux-20261023/preview-process.json。若预览服务已停止，直接打开单文件 HTML 仍可使用。
