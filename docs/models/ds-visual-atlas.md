# DS 鼠控版 c_0120 视觉图鉴

更新：2026-10-24

这是对真实 DS 模型的逐项视觉审计，不是只看参数名。审计实例使用仓库外模型副本，关闭呼吸/物理/眨眼以稳定截图，先建立干净基线，再逐项改变滑块、部件、动作、表情和控件并比较像素差异。审计证据和接触表保留在本地测试记录中，不随仓库分发。

## 1. 规模

- 247 参数、100 个 CDI 部件条目、运行时 92 个可查询部件、28 参数组。
- 44 个表情、8 个原生动作、42 个可用控件（35 个基础 + 7 个强特效）、32 个滑块。
- 专用适配表：`docs/models/ds-adapter.json`；视觉证据：`shots/sliders/`、`shots/parts/`、`shots/states/`、`shots/control-states/`、`shots/motions2/`、`shots/expressions/`。

## 4. 8 个原生动作

| 动作 | 时长 | 实际画面 | 结束残留/清场 |
| --- | --- | --- | --- |
| `idle` | 4s | 待机呼吸/眼神微动；没有场景道具 | 结束时 `paopao=1`（肉眼未见），日常待机能清掉 |
| `aidale` | 4.767s | 惊讶睁大眼 + 头顶锤子（Part162/11） | 没有参数残留；中性清场正常 |
| `selfie` | 3.3s | 双手举手机自拍，嘴张开 | `phone=1`；不清理会一直拿手机 |
| `selfieQuick` | 1.267s | 快速举手机 | `phone=1` |
| `ketchup` | 5s | 蛋包饭 + 酱瓶，wink | `point=0`、`danbaofan=1`；不清理会留下蛋包饭 |
| `openLid` | 1s | 手机开盖/手机手 | `phone=1` |
| `bubble` | 5s | 吹泡泡糖，3.5–4.8s 泡泡最明显 | 结束时参数回落；中性清场正常 |
| `splash` | 0.467s | 极短喷水，抽帧容易看不到 | 无参数残留 |

中性待机清场会把这些残留全部清掉；如果通过宿主 `play_animation` 直接播放，Uta 当前不会自动清场，调用方需要随后回待机或自行安排收尾。

## 5. 表情与控件

- 44 个表情逐个应用并截图；40 个有肉眼可见变化。
- 无可见变化的 4 个：`挤`、`魔爪换色`、`手机换色`、`love`，它们需要对应道具/状态（挤压、魔爪、手机、爱心）才可见。
- 表情接触表：`expression-sheet.png`；35 个基础控件接触表：`control-sheet.png`；新增 7 个强特效控件复用已验证的表情参数。
- 42 个控件分类、标签和基础开关审计见 `docs/models/ds-adapter.json` 与 `docs/workflow/CURRENT.md`。
- 控件关闭后的状态恢复：35 个基础控件逐个开/关，全部满足 `point=1`、`danbaofan/phone/bi/love=0`、活动控件清空。

## 6. 适配结论

1. 默认日常面捕可以只用 14 个脸参数 + 3 个头身参数，避免高级内部通道。
2. 点菜手不是部件，是 `point/pointX/Y` 参数姿态；使用时必须同时保证手姿态出现。
3. `蛋包饭`、`手机手`、`双手比耶`、`喵喵手`、`画笔`、`魔爪` 都是临时道具/手势，关闭时要恢复模型初始参数和控件/滑块快照。
4. `idle` 是安全的待机；`aidale/ketchup/selfie/openLid` 等场景动作有可见残留，日常编排要么不使用，要么在结束回待机。
5. 45 个备用部件当前不会被参数/控件激活；如果未来要开放，需要单独设计部件选择器，不应塞进现有滑块。
