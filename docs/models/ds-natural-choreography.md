# DS 自然编排记录

更新：2026-10-24
状态：用户已初步认可“克制”的观感，后续按本文档慢慢补。

## 1. 这次确定的方向

- 状态动作不再用“大幅转头 + 单个强表情”硬切，改为 2–4 步的小幅连续缓动：
  头、视线、眉、嘴、身体分别变化，步骤之间有先后，结束有回落。
- 预设不写 `ParamEyeLOpen/ROpen`，原生眨眼继续工作。
- 日常不使用场景道具动作；`selfie/ketchup/openLid` 等仍只作为显式动作，且需要收尾。
- 强特效不是禁用，而是**按情绪选择性使用**，并保留至少一个克制变体。

## 2. 两套包

### 通用包

`app/src/renderer/services/live2d/natural-presets.json`

- 18 个状态预设：日常待机、开心×2、委屈×2、生气×2、厌烦、倦怠、尴尬、害羞×2、思考、专注、好奇、惊讶、等待、测试。
- 只用标准参数，`controls: []`，不依赖任何模型自定义表情 ID。
- 适用于嘴角支持负值、头部角度范围足够的兼容标准模型；不适用时自动跳过。

### DS 专用包

`app/src/renderer/services/live2d/natural-presets.ds.json`

- 同样的 18 个动作骨架，叠加 DS 鼠控版的强特效控件。
- 只在模型同时有点菜手参数和 DS 控件时启用：
  `isDsMouseModel()` 检查 `pointX` 与 `蛋包饭/点菜按下/开心兴奋/脸红`。
- 其他模型继续走通用包，避免把 DS 的表情 ID 塞给不支持的模型。

### 选择与迁移

- `buildNaturalPresetsForModel()` 在构建默认预设时选择 DS 或通用包。
- `deskpet/natural-presets-v2:<model>` 一次性把已有预设桶里的同 ID 状态预设替换成自然版。
- 保留用户自己的「聆听记录」、自定义预设，以及 `工作·连续`、`空闲·窗边张望`。
- 用户删除或修改过的预设不会被反复覆盖（版本标记只执行一次）。

## 4. 已实测

- 真实 DS 迁移后：18 个自然预设 + `聆听记录` + `工作·连续` + `空闲·窗边张望`。
- 每条状态在 0.9s / 2.0s / 3.5s 截图检查入场、保持和特效；5 秒后开心/生气的强特效均回到待机。
- 正式 profile 的预设桶迁移、42 个控件加载、旧预设替换均已核对。
- 应用测试 **788 项（783 通过、5 跳过、0 失败）**，node/web 类型检查、构建通过。
- 视觉图鉴：`docs/models/ds-visual-atlas.md`；逐项截图保留在本地测试记录中，不随仓库分发。

## 5. 后续慢慢补

1. **直接播放场景动作的收尾**：`selfie/openLid` 会留手机，`ketchup` 会留蛋包饭；目前只有回日常待机会清。需要给宿主直接调用 `play_animation` 的场景动作补“结束清场/回待机”，或进一步限制为安全动作。这是下一步最值得做的工程项。
2. **个别预设观感微调**：开心兴奋的眯眼笑、生气强特效、哭的强度，等用户在实际使用中给具体反馈后再微调，不先大改。
3. **通用包的真实机型验证**：目前通用包只做了合成/内容测试，尚未在另一只兼容模型上实拍；以后换模型时先验证。
4. **45 个备用部件**：视觉审计中这些部件在所有动作/基础控件状态里都不可见（备用发型、耳朵、手部贴图、翅膀、手柄键鼠、颜色层）。暂不暴露；如果以后要做部件检查器，再单独设计，不能硬塞进现有滑块。
5. **提交与打包**：自然编排、连续表演、快捷面板和跨窗口模型同步已随 `b5542e3` 提交；正式候选 ZIP、日常 0.1.1 和 stable 包都未替换。等观感再稳定后按原流程打候选包并决定是否提升日常版本。
